# 격자 출격 시제품 — 주피터헬식 턴제 익스트랙션 (설계)

상태: 승인됨(2026-10-02). 목적은 **형태와 느낌 확인**이다. 완성도·밸런스는 목표가 아니다.

## 0. 의도

- 사용자: "완전 주피터헬처럼 … 형태만 볼 거니까 근거리 하나 원거리 하나만 … 액션감이 중요할 것 같아."
- 주피터헬의 핵심: **100% 턴제인데 연출이 턴을 기다리지 않아** 실시간 액션처럼 보인다. 행동마다 시간 비용이 있고, 내가 행동하면 그 시간만큼 모든 적이 함께 반응한다. 빨리 누르면 디아블로처럼, 손을 떼면 세계가 멈춘다.
- 성공 기준: 폰 세로 화면에서 한 판(출격 → 탐색 → 근접·원거리 전투 → 루팅 → 탈출)을 했을 때 "턴제인데 액션처럼 손맛이 있다"고 느껴진다.
- 범위 결정: 1인(동료는 나중에 칸 위에서 각자 턴을 갖는 방식으로), 에셋만 재사용하고 규칙·엔진·화면은 새로 만든다. 기존 파티 출격 모드는 그대로 둔다.

## 1. 한 판

- 타이틀에 `격자 출격 (시험)`(`data-testid="to-grid"`). 누르면 로딩 → 출격. 끝나면 결과 화면(가져온 가치, 누적 골드, `다시`/`타이틀`). 누적 골드는 localStorage `projr.grid.v1`(try/catch). 거점·상인·용병 없음.
- 지하 묘지 한 층, 시드로 생성: 약 48×48칸, 방 8~12개 + 복도, 문, 방 안 기둥. 시작 방 1, 탈출 지점 2(시작에서 먼 방).
- 위험 시계(턴 = 행동 시간 1.0): 200턴 "발소리가 늘었다"(잠든 적 일부 깨어남), 300턴 증원(탈출 지점 근처 제외한 복도에 해골 무리) + 탈출 지점 하나 닫힘. 시제품이라 수치는 대충.
- 탈출: 탈출 지점 칸 위에서 3턴(쉬기·행동 무관하게 3.0 시간) 머물면 성공. 맞아도 끊기지 않는다(시제품 단순화). HP 0이면 실패 — 이번 판 전리품을 잃는다.

## 2. 규칙 (`src/sim/grid/*`, 결정적, DOM·three·Math.random 금지)

- 칸 좌표 정수. 칸 종류: 바닥, 벽, 문(닫힘/열림 — 닫힌 문은 시야를 막고, 들어가면 열린다), 기둥(막힘, 엄폐), 탈출 지점(바닥).
- **시계**: 모든 존재가 `nextAt`(시간)을 가진다. 플레이어가 행동하면 `nextAt += 비용`. 그다음 `nextAt`이 플레이어의 새 `nextAt`보다 **작은** 적들이 시각 순으로(같은 시각이면 id 순) 행동한다. 같은 시각이면 플레이어가 먼저다. 플레이어 차례가 오면 멈추고 입력을 기다린다. 모든 결과는 `{t, type, ...}` 이벤트로 남는다(`t` = 그 행동이 시작된 시각) — 화면이 이 순서·시각으로 연출한다.
- 행동 비용: 이동 1.0(대각 1.0), 근접 1.0, 사격 1.0, 장전 1.5, 쉬기 1.0, 물약 1.0, 줍기/상자 열기 0.5.
- 8방향 이동. 대각 이동은 양옆 두 칸 중 하나라도 막히면 불가(모서리 끼기 금지).
- **장검(근접)**: 적이 있는 칸으로 이동 = 범프 공격. 피해 6~9, 명중 90%.
- **석궁(원거리)**: 사거리 8, 피해 5~8, 탄창 1(쏘면 빈 상태, 장전 1.5). 볼트 시작 12. 사선: 칸 중심끼리의 선(브레젠험)에 벽·닫힌 문·기둥·다른 존재가 있으면 못 쏜다.
- **명중률**: 85% − 4%×(거리−1). 표적이 엄폐 중이면 −30%. 엄폐 = 표적 바로 옆 칸 중 사수 쪽(사수→표적 방향과 내적 > 0)에 벽·기둥이 있다. 최소 5%. 적 사격도 같은 공식.
- **적(에셋의 해골)**:
  - 해골 졸개(Skeleton_Minion): HP 10, 속도 1.0, 근접 3~5.
  - 해골 석궁병(Skeleton_Crossbow): HP 8, 속도 1.0, 사거리 7, 3~5. 3~6칸을 유지, 붙으면 한 칸 물러남, 사선 없으면 사선 잡는 칸으로.
  - 해골 전사(Skeleton_Warrior): HP 20, 이동 비용 1.4(느림), 근접 6~9.
  - 처음엔 잠들어 있다. 플레이어가 시야(반경 8, 그림자 투사) 안에 들어오면 깨어나고 같은 방 무리를 깨운다. 사격 소리는 반경 6 안 잠든 적을 깨운다. 깬 적은 마지막으로 본 자리를 쫓는다(BFS 길찾기, 다른 적은 장애물 취급하되 막히면 기다림).
- 플레이어 HP 30, 물약(HP +12) 시작 2.
- 시야: 플레이어 기준 반경 8 그림자 투사. 보이는 칸 / 본 적 있는 칸 / 모르는 칸.
- 상자(chest 에셋): 열면(0.5) 가치 아이템 1~3(이름+금액), 볼트 0~4, 물약 확률. 짐 제한 없음 — 가치 합계만.
- 결정성: 시드 + 입력 순서가 같으면 같은 판. 테스트는 입력 목록으로 돌린다.

## 3. 액션감 (가장 중요)

목표: **판정은 즉시, 연출은 끊김 없이 겹쳐서.** 입력은 절대 연출을 기다리지 않는다.

- **위치 쫓기**: 논리 위치는 즉시 바뀐다. 모델은 `pos += (target − pos) × (1 − e^(−k·dt))`로 쫓는다(k ≈ 18, 거리가 멀수록 빨리 따라와서 뒤처짐 상한이 있다). 걷기 애니메이션은 실제 화면 이동 속도로 재생 속도를 맞춘다.
- **턴 안의 시간 압축**: 한 번의 입력이 만든 이벤트들을 `t` 순서로 재생하되, 턴 1.0을 화면 0.18초로 압축한다. 다음 입력이 들어오면 남은 연출은 즉시 따라잡기 속도(×3)로 감는다 — 빨리 누를수록 연출도 빨라진다.
- **꾹 누르기**: 스틱/키를 누르고 있으면 0.14초마다 한 걸음(첫 걸음은 즉시, 두 번째부터 반복). 적이 새로 보이면 반복을 멈춘다(실수 방지). 사격 버튼도 누르고 있으면 쏨·장전을 자동 반복하지 않는다(한 번 = 한 행동).
- **때리는 맛**: 근접은 내딛는 찌르기(모델이 표적 쪽으로 0.3칸 튀었다 돌아옴) + 피격자 번쩍임 + 0.06초 히트스톱(화면 연출만 멈춤) + 피격자 0.15칸 밀림 흔들림. 치명(최대 피해)이면 카메라 흔들림.
- **쏘는 맛**: 볼트는 눈에 보이는 투사체(빠른 직선, 꼬리), 명중 시 번쩍임·숫자, 빗나가면 "빗나감"과 벽에 꽂히는 작은 먼지. 사수 반동(뒤로 0.1칸).
- **적의 턴도 액션으로**: 여러 적이 같은 턴에 행동하면 0.03초씩 엇갈려 거의 동시에 움직인다(한 놈씩 기다리지 않음).
- **위협 읽기**: 적 머리 위 의도 아이콘(다가옴/조준/근접 준비)이 보인다. 석궁병이 나를 조준할 수 있으면 붉은 조준선이 깔린다(다음 행동에서 쏠 것이라는 예고).
- 숫자: 피해 숫자 크게, 내 피격은 붉게. 죽음은 쓰러짐 애니메이션 + 뼈 흩어짐 파티클 없이(에셋 애니메이션만).
- 소리는 이번 범위 밖.

## 4. 조작

- **모바일 세로(우선)**: 왼쪽 아래 떠오르는 스틱 — 8방향으로 맞춰(데드존 0.35) 한 번 밀면 한 칸, 꾹 밀면 연속. 바닥 칸 탭 = 길 찾아 걷기(적이 보이거나 맞으면 멈춤), 적 탭 = 표적 지정. 오른쪽 아래 버튼: **사격**(크게, 현재 표적과 명중률 % 표시, 장전 필요하면 "장전"으로 바뀜), 쉬기, 물약, 표적 넘기기 ◀▶. 모든 버튼 ≥ 56px.
- 표적 자동: 보이고 사선 있는 적 중 지난 표적(살아 있고 보이면), 아니면 가장 가까운 적.
- **PC**: WASD·QEZC 또는 숫자패드 8방향(꾹 누르면 연속), F 사격, Tab 표적 넘기기, R 장전, Space/숫자5 쉬기, 1 물약, E 줍기/열기(상자 칸으로 범프해도 열림), 마우스 왼쪽 = 칸 이동/적 지정.
- **패드**: 왼쪽 스틱 8방향, Ⓐ 사격, LB/RB 표적, Ⓧ 장전, Ⓨ 물약, Ⓑ 쉬기.
- 카메라: 위에서 내려다보는 각도(앙각 약 60°, 회전 없음), 기존 줌 버튼·핀치·휠 재사용, 플레이어를 부드럽게 따라감. 세로·가로 둘 다 동작(세로 우선).

## 5. 코드 구조

- `src/sim/grid/`: `types.ts`, `mapgen.ts`, `fov.ts`, `path.ts`, `clock.ts`(차례), `actions.ts`(이동·범프·사격·장전·쉬기·물약·열기), `ai.ts`, `combat.ts`(명중·엄폐·피해), `gridSim.ts`(입구: `GridSim.create(seed)`, `act(action)`, `state`, `events`). 기존 `core/rng`만 사용.
- `src/view/grid/`: 지형 메쉬(바닥·벽·기둥·문·탈출 표시, 기존 env 에셋), 존재 모델(기존 캐릭터 에셋·애니메이션), 쫓기·이벤트 재생기, 투사체·숫자·조준선, 시야 어둠.
- `src/ui/grid/`: 출격 화면, HUD(HP·볼트·탄창·턴·가치·위험 시계), 터치 컨트롤, 결과 화면. 입력은 기존 `Input`/`TouchState`를 쓰되 8방향 양자화·반복은 새 모듈.
- `src/app/gridFlow.ts`: 타이틀 → 로딩 → 출격 → 결과.
- 300줄 제한·계층 규칙 그대로. 기존 파티 출격 코드는 건드리지 않는다.

## 6. 테스트

- 단위(sim): 차례 순서(느린 전사는 두 번에 한 번 꼴), 범프 공격, 대각 모서리 금지, 사선(벽·적에 막힘), 명중률(거리·엄폐·최소), 장전 상태, 시야(벽 뒤 안 보임), 적 깨어남(시야·소리), 석궁병 거리 유지, 탈출 3턴, 사망 시 전리품 상실, 결정성(같은 시드+입력 = 같은 결과).
- 단위(view 순수부): 쫓기 공식 상한, 이벤트 재생 순서·압축, 입력 8방향 양자화·반복.
- e2e: 타이틀 → 격자 출격 → 디버그 훅으로 한 걸음·사격 → 결과까지, 콘솔 오류 0. 세로 뷰포트에서 버튼 ≥ 56px.
