# 격자 로그라이크 — 시스템 설계 (각인 · 장비 성장 · 로그라이크 기본)

상태: 초안(2026-10-03). 기반: `2026-10-03-grid-roguelike-v1-design.md`(3층·원소·폭발물·적·직업 — 일부 구현, 나머지는 이 문서와 함께 진행).

## 0. 의도와 결정 기록

- 사용자: "소음·함정·미확인 포션·스크롤 등 로그라이크 기본 요소는 다 넣을 예정. 거기에 우리만의 독특한 시스템이 필요" — DCSS(신·스킬), Path of Achra(조건부 빌드), SPD(강화·특성), Dead Cells(색 스탯·조합)를 모두 재미있게 했다.
- 합의된 방향:
  - **턴제 뼈대 유지**(멈춰 생각 + 몰아치는 연출 + 연쇄 빌드). 데드셀은 손맛·빌드만 가져온다.
  - **중심 시스템 = 각인**: 무기에 박히는 "~할 때 ~한다" 조건부 효과. 우리 고유 소재(교체·시간 비용·밀치기/벽·엄폐·기습·원소)를 조건으로 쓴다.
  - 각인은 **습득 중심**(룬석·각인 주문서·제단) + **레벨업 3지선다** + **직업은 시작 각인 1개와 전용 각인 일부**.
  - 무기는 **SPD식**: 무기군 9종 × 등급 3단계 + 강화 수치 + 각인. 다양성은 각인이 맡는다. 미확인·저주, 드문 이름 있는 무기.
  - 각인·강화 옮기기는 **층마다 있는 룬 대장간**에서(룬 조각 1개), 어디서든은 **이전 주문서**로. 각인을 룬석으로 **추출**(단계 −1)해 보관 가능.
  - 등급 요구치 = **힘**(SPD식, 힘 물약). 방어구도 같은 틀(등급 3 + 강화 + 각인 1칸).
- 성공 기준: 한 판 안에서 각인 2~4개가 맞물려 "연쇄가 터지는" 순간이 생기고, 주운 무기·미확인 물건마다 판단할 거리가 있다.

## 1. 장비

### 1.1 무기
- 무기군 9종(기존 규칙 유지): 단검·장검·도끼·창·철퇴 / 활·석궁·투척·지팡이(화염·서리·번개·독).
- 등급 3단계(예: 장검 → 기사검 → 룬검). 등급 한 단계 ≈ 강화 +2~3 차이. 깊은 층일수록 높은 등급.
- **힘 요구치**: 1등급 10, 2등급 12, 3등급 14(시작 힘 10). 모자란 1점마다 명중 −10%p, 행동 시간 +10%.
- **강화 수치** +0~: 피해 +1(근접)/+1(원거리), 명중 +2%p씩. **+3, +6에서 각인 칸 +1**(기본 1칸).
- 무기는 손 2칸(교체 0.5턴) + 가방 8칸(기존).

### 1.2 방어구
- 등급 3단계(가죽·사슬·판금), 피해 감소 1/2/3 + 강화마다 +0.5(내림). 힘 요구치 10/12/14(모자라면 회피·이동 시간 페널티). 각인 1칸(방어 계열).

### 1.3 미확인 · 저주
- 주운 장비는 강화 수치·각인이 미확인일 수 있다. 착용하고 50턴(또는 적 10 처치) 지나면 밝혀진다. 확인 주문서로 즉시.
- 저주(약 10%): 음수 강화 또는 나쁜 각인, 손·몸에서 뗄 수 없음. 정화 주문서로 해제.

### 1.4 이름 있는 무기(드묾)
- 고정된 고유 각인 1개(각인 풀에 없는 효과). 보스·보물방 보상. v2는 3종.

## 2. 각인 (중심 시스템)

### 2.1 구조
- 각인 = **조건(트리거) + 효과**, 단계 1~3(단계마다 수치 상승).
- 무기·방어구의 각인 칸에 박힌다. 손에 들고 있는(방어구는 입은) 장비의 각인만 작동 — 단, "교체할 때"류는 교체로 **들게 되는** 무기의 각인이 작동.
- 화면: 각인이 터질 때마다 그 각인 아이콘 + 짧은 문구가 머리 위에 뜬다(연쇄가 읽혀야 한다).

### 2.2 트리거(우리 고유 소재)
교체할 때 · 처치할 때 · 기습(잠든/못 알아챈 적) · 밀쳐 벽/적에 박을 때 · 엄폐 뒤에서 쏠 때 · 원소 상태인 적을 칠 때 · 연속으로 같은 적을 칠 때(3타) · 피격될 때 · 쉬기(대기)할 때 · 층 첫 전투 · 체력 30% 이하일 때.

### 2.3 초안 목록(v2 15개 + 직업 전용 6개)
| 각인 | 효과(1단계) |
|---|---|
| 기세 | 처치할 때 다음 행동 시간 −50% |
| 칼바꿈 | 교체할 때 교체 시간 0, 다음 공격 피해 +50% |
| 연환 | 교체로 든 무기로 즉시 1회 공격(약화 50%) |
| 벽치기 | 밀쳐 벽에 박으면 주변 1칸에 충격파 3 |
| 점화 | 밀쳐 벽에 박으면 불 붙임 |
| 그림자 | 기습 시 시간 비용 0 |
| 잠재우기 | 기습으로 처치하면 주변 적이 깨어나지 않음 |
| 관통 | 엄폐 뒤 사격이 일렬 관통 |
| 확산 | 원소 상태인 적을 처치하면 그 상태가 주변으로 번짐 |
| 증폭 | 원소 상태인 적에게 피해 +30% |
| 삼연타 | 같은 적 3타째 피해 ×2 + 밀치기 |
| 반격 | 피격될 때 25% 확률로 즉시 반격 |
| 숨고르기 | 쉬기할 때 체력 +2, 다음 공격 명중 +20%p |
| 첫수 | 층 첫 전투의 첫 공격 피해 ×2 |
| 배수진 | 체력 30% 이하에서 피해 +40% |
| (전사) 철벽 | 피격될 때 다음 피격 피해 −50% |
| (전사) 돌진 강화 | 돌진 베기 거리 3칸 + 밀치기 |
| (사냥꾼) 연사 | 같은 적에게 연속 사격 시 두 번째부터 시간 −30% |
| (사냥꾼) 매복 | 쉬기 후 첫 사격 치명 확정 |
| (마법사) 원소 공명 | 서로 다른 원소 둘이 걸린 적은 폭발 |
| (마법사) 충전 | 처치할 때 지팡이 충전 +1 |

### 2.4 얻는 길
- **룬석**: 상자·정예·보물방에서. 빈 칸에 박기(어디서나, 무료).
- **각인 주문서**(미확인 주문서 중 하나): 손에 든 무기에 무작위 각인.
- **제단**: 층마다 낮은 확률, 3개 중 1개.
- **레벨업**: 3지선다(각인 / 기존 각인 단계 +1 / 스탯). 보유 각인과 같은 트리거·계열이 나올 확률 가중.
- **직업**: 시작 각인 1개(전사 벽치기 · 사냥꾼 관통 · 마법사 확산), 전용 각인은 그 직업의 레벨업·제단에만.

### 2.5 옮기기 · 추출
| 행동 | 장소 | 비용 |
|---|---|---|
| 강화 + 각인을 새 무기로 옮기기 | 룬 대장간 | 룬 조각 1 |
| 각인 하나를 룬석으로 추출 | 룬 대장간 | 무료, 단계 −1(1단계면 사라짐) |
| 룬석 박기 | 어디서나 | 무료(빈 칸 필요) |
| 어디서든 옮기기 | 이전 주문서 | 주문서 소모 |

## 2.6 콤보 · 회피 · 패링 (사용자 결정 2026-10-03)

- **돌진·콤보는 전부 각인으로 얻는다**(기본기 아님). 동작 라이브러리(UAL 1·2 무료판)에서 가능한 콤보를 각인으로 만든다:

| 각인 | 동작 | 효과 |
|---|---|---|
| 돌진 베기 | Sword_Dash(2편) | 직선 2칸 앞 적에게 한 칸 뛰어들며 공격(이동+공격 한 행동, 무기 시간 +0.3) |
| 밀치고 쏘기 | Shield_OneShot/Melee_Hook → Pistol_Shoot | 붙은 적을 1칸 밀친 뒤 같은 행동에서 손 2칸 중 원거리 무기로 한 발 |
| 방패 돌격 | Shield_Dash(2편) | 직선 2칸 돌진, 경로의 적 밀침, 벽 충돌 기절 |
| 도약 내려찍기 | NinjaJump Start/Idle/Land(2편) | 2~3칸 도약, 착지 주변 1칸 공격 |
| 미끄러져 뒤잡기 | Slide Start/Loop/Exit(2편) | 붙은 적의 등 뒤로, 다음 공격 뒤치기 ×2 |
| 던지고 덮치기 | OverhandThrow → Sword_Dash | 투척 명중 시 그 적에게 돌진 |
| 3연타 마무리 | Sword_Regular A→B→C | 같은 적 3타째 ×1.5 + 밀치기 |
| 주먹 연타 | Punch_Jab→Cross→Hook | 단검/맨손 0.5턴 3연타 |
| 조준 사격 | Pistol_Aim | 1턴 조준 → 다음 사격 치명 확정 |
| 집중 시전 | Spell Enter/Idle/Shoot | 2턴 모아 범위 +1, ×1.5 |
| 잠행 | Crouch Idle/Fwd | 소음 반경 절반, 기습 확률 증가 |
| 통 밀기 | Push_Loop | 기름통을 한 칸 밀기(밀고 쏘면 폭발 콤보) |

- **회피 = 제자리 위빙 동작만**(칸 이동 없음). 회피율 기본 5%(가벼운 갑옷·단검·각인으로 상승). 무료판에 위빙 동작이 없어 같은 리그에 Blender로 좌·우 위빙 2종을 만든다. 순서는 이벤트 순서 그대로: 적 공격 → 위빙 → (각인 "반격") 반격. 빠른 무기는 공격 → (되받아치기) 위빙. 각인 "치고 빠지기" = 공격 직후 받는 반격의 회피율 대폭 상승(이동 없음).
- **패링 = 제자리**: 칼(Sword_Block) 또는 방패(Idle_Shield/Shield_OneShot). 각인 "되받아치기"(패링 후 반격)·"방패 반격"(막고 밀쳐내기). 보스·치명타를 방패로 막으면 Idle_Shield_Break + 1턴 무방비.
- 추가 트리거: 회피할 때 · 패링할 때 · 마무리 일격 때 · 돌진할 때 · 착지할 때.

## 3. 성장

- **숙련 3계열 + 비전**: 칼날(단검·장검·도끼), 충격(철퇴·창), 사격(활·석궁·투척), 비전(지팡이). 그 계열 무기로 적을 칠수록 숙련(1~5). 숙련 단계마다 그 계열 피해 +5%, 해당 계열 무기의 각인 효과 +10%.
- **레벨**: 경험치(처치), 레벨업 = 최대 체력 +4 + 3지선다(2.4).
- **힘**: 10에서 시작, 힘 물약 +1.
- **강화 자원**: 강화 주문서(무기·방어구 +1), 룬 조각(옮기기 화폐, 대장간에서 강화 +1에도 쓸 수 있음: 2개).

## 4. 로그라이크 기본

- **소음**: 행동마다 소음 반경(걷기 1, 근접 3, 석궁·폭발 6, 문 열기 2). 잠든 적은 반경 안에서 깰 확률. 맹약/각인으로 조절.
- **함정**(숨어 있음, 발견 확률 / 탐색 행동으로 주변 확인): 가시(피해), 경보(주변 적 깨움), 독가스, 화염, 순간이동, 그물(1턴 묶임). 모듈 팩의 가시 함정·함정 문 모델 사용.
- **미확인 물약**(판마다 색이 무작위로 대응): 치유, 힘, 해독, 투명(적이 못 봄 10턴), 화염(마시면 화상 — 던지면 화염병), 독, 빙결, 신속(행동 시간 −50% 5턴), 정신 착란.
- **미확인 주문서**(판마다 룬 문자가 무작위): 확인, 강화, 정화, 각인, 이전, 순간이동, 지도, 공포(주변 적 도주), 소음(적 끌어옴), 재충전.
- 처음 쓰면 정체가 밝혀지고 그 판 동안 기억된다.

## 5. 맹약(신의 축소판) — v2 이후

층 사이 제단에서 하나: 질주(빠른 행동 연속 보상·쉬기 금지), 철벽(교체 금지·한 무기 극대화), 사냥(기습·원거리 보상·근접 처치 벌칙). 본 문서 범위 밖, 설계만 예약.

## 6. 화면

- 각인 발동 표시(아이콘 + 문구), 가방에서 장비 상세(등급·강화·각인·미확인 표시 `?`), 대장간 창(옮기기·추출), 레벨업 3지선다 카드, 미확인 물약·주문서 이름(색·룬 문자 → 밝혀지면 이름), 함정 표시(발견 후).

## 7. 범위와 순서

1. v1 남은 것: 직업 선택, 원소·폭발물, 새 적(구울·마법사·보스), 3층·계단, 경험치/레벨.
2. 로그라이크 기본: 소음, 함정, 미확인 물약·주문서.
3. 장비 성장: 등급 3·힘·강화·미확인·저주.
4. **각인**: 15개 + 직업 전용 6개, 룬석·주문서·레벨업 3지선다, 발동 표시.
5. 룬 대장간(옮기기·추출), 이전 주문서, 이름 있는 무기 3종.
6. 숙련 3계열.
- 맹약·동료는 이후.

## 8. 테스트

- 각 트리거가 정확한 순간에 한 번 발동(교체·처치·기습·벽치기·엄폐·원소·3타·피격·쉬기·첫 전투·저체력), 연쇄 상한(한 행동에서 같은 각인 재발동 금지 → 무한 루프 없음), 결정성.
- 미확인: 판마다 대응 무작위·같은 시드 동일, 사용 후 식별 유지. 저주 장비는 뗄 수 없음/정화로 해제.
- 힘 부족 페널티, 강화 각인 칸(+3·+6), 옮기기·추출 비용, 레벨업 가중.
