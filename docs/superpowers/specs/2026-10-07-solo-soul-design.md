# 1인 원정 · SF 빈 몸과 판타지 영혼 설계 (2026-10-07)

`2026-10-07-rule-traits-design.md`의 **파티 전제 부분**(3인 원정, 직업 간 시너지 위주의 듀오, 동료 유틸리티 AI)을 대체한다. 같은 문서의 카드 체계(법칙·증폭·변환·강화), 태그 공명, 연쇄 엔진, 성장 곡선, 몬스터 밀도, 귀환 신호기는 그대로 쓴다.

## 0. 왜 바꾸나

- 셋이 동시에 싸우는 연출은 읽기 어렵고, 동료 AI와 역할 구분이 계속 문제였다.
- 원하는 것은 Jupiter Hell 같은 접근성(바로 이해되는 손맛), Path of Achra·디아블로 같은 빌드 깊이, 그리고 이 게임만의 특징이다.
- 이 게임만의 특징: **SF 클론 몸 + 판타지 영혼**, **영혼 여러 개 조합**, **조건 발동 연쇄**.

## 1. 원정 구조

- **한 판 = 클론 하나:** 매 원정은 클론 한 명이 내려간다. 클론은 한 번의 목숨이다.
- **영혼석은 기지로:** 주운 영혼석은 그 자리에서 쓰지 않는다. 귀환하거나 귀환 신호기를 쓸 때 함께 기지로 전송되고, 다음 클론을 만들 때 넣는다.
- **죽으면:** 그 몸에 넣은 영혼과, 아직 전송하지 않은 영혼이 함께 사라진다. 많이 넣을수록 강하고 잃을 때 아프다.
- **클론 만들기:** 기지 연구실에서 빈 몸을 출력하고(생체 소모), 영혼을 0개 이상 넣어 출발한다.

## 2. 두 형태

### 2.1 빈 몸 (SF)

- 영혼 0개. 총 + 슈트로 싸운다. 언제든 고를 수 있다.
- 기지에서 **총 업그레이드**와 **슈트 업그레이드**로 판타지 직업과 같은 수준까지 강해진다.
- 레벨업 카드는 총·슈트 조건 기술 카드다(§4.7).
- 궁극기: **전투 드론 투입.** 지정한 칸에 드론을 띄워 몇 턴 동안 주변 적을 자동 사격한다.

### 2.2 영혼 주입 (판타지)

- 영혼 1개 이상. 총은 쓰지 않고, 넣은 영혼의 직업으로 완전히 판타지 형태가 된다(외형, 무기, 기술).
- 레벨업 카드는 넣은 직업들의 조건 기술 카드다.
- 직업마다 궁극기가 하나씩 있다.

## 3. 판타지 직업 6종

디아블로의 유명 기술을 오마주하되, 이름과 표현은 우리 것으로 하고 조건 발동 체계에 맞춰 바꾼다. 기본 구성(전사·마법사·궁수·성직자·도적·강령술사)은 장르 표준이라 그 자체로 모방이 아니다. 아이콘·이펙트·소리·설명문은 직접 만들거나 라이선스가 분명한 에셋을 쓴다.

| 직업 | 핵심 | 궁극기 (위치 지정) |
|---|---|---|
| 전사 | 맞을수록 터지는 피격 엔진 | 대지 강타: 지정 칸으로 도약해 내려찍고 주변 기절 |
| 마법사 | 원소 반응 엔진 | 순간이동: 지정 칸으로 이동, 출발·도착 지점 폭발 |
| 궁수 | 표식 엔진 | 화살비: 지정 범위에 화살 폭우 |
| 성직자 | 보호막 엔진 | 신성 결계: 지정 범위 아군 무적 + 적 정화 피해 |
| 도적 | 함정과 기 모으기 (디아블로 2 어쌔신 쪽) | 그림자 분신: 지정 칸에 분신 둘 소환 |
| 강령술사 | 시체 엔진 | 골렘 생성: 지정 칸의 시체를 모아 골렘 소환 |

강령술사는 지금 마법사의 상위 직업인데 기본 직업으로 올린다. 1인 체제에서 상위 직업(전직)을 유지할지는 별도로 정한다(도적의 상위 직업 암살자는 도적 자체와 겹침).

## 4. 카드 = 기술

레벨업 카드가 곧 기술이다. 직업마다 조건 기술 카드 8장(법칙·증폭·변환, 법칙은 강화 가능). 아래는 시작 목록이고 수치는 봇으로 맞춘다.

### 4.1 전사
- 회오리 베기(법칙) 1턴 안 2회 피격 → 주변 4칸 베기 / **강화** 주변 적 끌어당김
- 도약 강타(법칙) 3칸 밖 적에게 공격 → 도약해 착지 범위 피해 / **강화** 착지 기절
- 전투 함성(법칙) 위기 → 주변 적 공포(1턴 도주) / **강화** 아군 소환수도 피해 +30%
- 가시 갑옷(법칙) 근접 피격 → 받은 피해 반사 / **강화** 반사 100%
- 분노 축적(법칙) 피격마다 분노 → 다음 공격 추가 피해 / **강화** 소모 시 범위
- 철벽 반격(변환) 반격 피해 +50%, 25% 기절
- 땅 울림(법칙) 큰 피격 → 주변 기절 / **강화** 노출 추가
- 굳건함(증폭) #방패 1당 받는 피해 -5%

### 4.2 마법사
- 얼음 구체(법칙) 세 번째 시전 → 날아가며 사방으로 얼음 파편 / **강화** 빙결
- 연쇄 번개(법칙) 치명 → 번개가 적 사이를 튐 / **강화** 튐 횟수 +2
- 메테오(법칙) 화상 걸린 적 처치 → 그 자리에 운석 / **강화** 운석 자리 불바다
- 원소 순환(법칙) 공격마다 화상 → 냉기 → 감전 / **강화** 두 원소씩
- 연쇄 반응(법칙) 반응 → 주변에 같은 원소 / **강화** 2칸
- 마력 보호막(변환) 받은 피해 30%가 보호막
- 서리 갑옷(법칙) 피격 → 공격자 냉기 / **강화** 빙결
- 반응 증폭(증폭) 원소 태그 종류당 반응 피해 +40%

### 4.3 궁수
- 다중 사격(법칙) 표식 적 처치 → 주변 적 모두에게 화살 / **강화** 표식도 옮김
- 연속 사격(법칙) 제자리 3턴 → 같은 적에게 연사 / **강화** 관통
- 관통 화살(법칙) 사격 → 뒤의 적 관통 / **강화** 직선 전체
- 유도 화살(법칙) 빗나감 → 다음 적에게 휘어 감 / **강화** 치명
- 사냥 표식(법칙) 첫 사격 표식 / **강화** 처치 시 표식 이동
- 덫 사격(법칙) 대기 → 주변에 가시 덫 / **강화** 2칸
- 집중 사격(증폭) 제자리 연속 사격마다 치명 +10%
- 사냥꾼의 눈(증폭) #원거리당 표식 피해 증가

### 4.4 성직자
- 축복의 망치(법칙) 피격 → 나를 중심으로 도는 망치 생성 / **강화** 망치 2개
- 신성 방패(법칙) 전투 시작 → 보호막 / **강화** 보호막이 있으면 반격
- 보호막 폭발(법칙) 보호막 파괴 → 주변 피해 / **강화** 기절
- 심판 낙인(법칙) 적중 5회 → 신성 폭발 / **강화** 3회
- 응답하는 기도(법칙) 위기 → 치유 + 보호막 / **강화** 소환수 포함
- 넘친 은총(변환) 넘친 치유 → 보호막 2배
- 생명 전이(변환) 치유량 30% → 가까운 적 피해
- 신성 방벽(증폭) #방패·#치유당 보호막 +15%

### 4.5 도적
- 번개 함정(법칙) 대기 → 바닥에 번개 함정 / **강화** 함정 2개
- 화염 함정(법칙) 이동 후 → 떠난 칸에 화염 함정 / **강화** 폭발
- 기 모으기(법칙) 연속 3회 적중 → 다음 일격에 기 폭발 / **강화** 5회 누적 시 범위
- 그림자 걸음(법칙) 처치 → 은신 + 가까운 적 곁으로 / **강화** 즉시 공격
- 급소 찌르기(법칙) 적 상태 1개당 피해 +25% / **강화** +40%
- 처형(법칙) 체력 25% 미만 즉사 / **강화** 35%
- 독 바르기(변환) 적중마다 중독
- 기습(증폭) 은신 공격 × (1 + #은신 × 0.5)

### 4.6 강령술사
- 시체 폭발(법칙) 처치 → 시체가 터져 주변 피해 / **강화** 폭발로 죽은 시체도 터짐
- 해골 일으키기(법칙) 시체 곁에서 대기 → 해골 소환 / **강화** 해골 궁수
- 뼈 창(법칙) 치명 → 일렬 관통 뼈 창 / **강화** 두 줄
- 뼈 감옥(법칙) 위기 → 주변 적 1턴 묶음 / **강화** 묶인 적 노출
- 생명 흡수(법칙) 시체 폭발 → 피해의 20% 회복 / **강화** 소환수도 회복
- 저주(법칙) 적중 → 받는 피해 증가 저주 / **강화** 저주가 옮음
- 망자의 군세(증폭) 소환수 1당 내 피해 +8%
- 뼈 갑옷(변환) 소환수가 받는 피해 일부를 대신 받음

### 4.7 빈 몸 (총·슈트)
- 관통탄(법칙) 탄창 마지막 발 → 관통 / **강화** 매 3발
- 반격 사격(법칙) 회피 성공 → 공격자에게 사격 / **강화** 2발
- 과열탄(법칙) 3연속 명중 → 화상 / **강화** 폭발
- 즉시 재장전(법칙) 처치 → 탄창 채움 + 다음 사격 치명 / **강화** 2연속
- 개머리판 밀치기(법칙) 붙은 적에게 → 밀쳐 기절 / **강화** 벽에 부딪히면 추가 피해
- 슈트 과부하(법칙) 위기 → 1턴 행동 2번 / **강화** 층당 → 전투당
- 산탄 확산(증폭) 근접 사격 피해 +30%
- 표적 분석(변환) 명중률 넘친 만큼 치명 확률

## 5. 영혼 여러 개 (조합 직업)

- 한 몸에 넣을 수 있는 영혼은 **기본 2개**, 기지 업그레이드마다 **1개씩 추가**, 최종적으로 **제한 없음**.
- 넣은 모든 직업의 카드가 레벨업 때 함께 나온다(가진 태그 가중치 규칙은 그대로).
- **궁극기는 영혼마다 하나씩**, 쿨타임은 따로 돈다. 사용할 때 위치를 직접 지정한다.
- **조합 카드:** 한 몸에 두 직업의 영혼이 함께 있을 때만 나온다(직업 쌍 15가지 × 1장). 기존 듀오 카드 10장을 바꿔 쓰고 5장을 새로 만든다. 예: 전사 + 강령술사 → 회오리로 벤 적이 시체 폭발.
- 영혼 수가 많아질수록 카드 풀이 흩어지므로, 직업당 카드가 고르게 나오도록 제시 규칙을 조정한다(직업마다 최소 1장 보장 등).

## 6. 기지

- **연구실:** 클론 출력, 영혼 주입, 영혼 보관(전송된 영혼 목록).
- **작업장:** 총 업그레이드, 슈트 업그레이드, 영혼 칸 확장.
- **남는 클론의 일:** 원정에 가지 않는 클론은 놀지 않는다.
  - 던전 자원 채취(자동 원정으로 광석·생체를 벌어옴)
  - 거점 주변 땅 정리(Tiny Terraces처럼 알아서 돌·덤불을 치우고 길을 내는 모습이 보임)
  - 습격 때는 함께 방어
- **습격:** 지금 클론과 남는 클론들, 기지 시설(망루, 포탑)이 함께 막는다.

## 7. 소환수 (파티 시스템 재활용)

- 파티용으로 만든 동료 AI(유틸리티 점수, 돌진, 대상 유지)를 소환수에 쓴다.
- 대상: 해골, 해골 궁수, 골렘, 그림자 분신, 전투 드론, 축복의 망치(궤도형).
- 소환수의 행동도 연쇄 엔진을 탄다(소환수의 처치 → 주인의 처치 발동 등).

## 8. 첫 임무와 영혼석 튜토리얼

1. **빈 몸 + 총으로 출발**(첫 판은 항상 빈 몸).
2. 지하 1층에서 첫 영혼석과 자원을 얻는다.
3. 1층 중간쯤 귀환 신호기로 귀환 → 거점 업그레이드(총 또는 슈트) → 던전 복귀.
4. 1층 클리어 → 귀환. 영혼석이 기지로 전송된다.
5. **영혼석 튜토리얼:** 첫 빈 몸 판이 끝난 뒤, 연구실에서 새 클론에 영혼을 넣는 법을 안내한다. 이후 영혼 2개 조합은 두 번째 영혼을 얻었을 때 안내한다.
6. 그다음부터 자유 진행(첫 습격은 기존 일정 규칙).

화면 안내는 짧은 체크리스트로만 한다.

## 9. 연출 원칙

- 화면의 주인공은 한 명이다. 모션과 이펙트를 그 클론에 몰아준다.
- 조건 기술마다 고유 이펙트(회오리 베기의 원형 칼날 궤적처럼).
- 몰살은 무리가 한꺼번에 쓰러지는 장면, 피, 쌓이는 시체로 보여준다. 배너는 띄우지 않는다.
- 카드 이름은 로그로, 화면은 이펙트와 `연쇄 ×n`, 반응 이름, 피해 숫자만.

## 10. 기존 것과의 관계

- **유지:** 카드 체계, 태그 공명, 연쇄 엔진, 레벨 성장 곡선, 영혼의 기억(영혼마다 붙는 시작 규칙), 원소 반응, 귀환 신호기(계획 B), 몬스터 밀도와 졸개(계획 B), 사망 연출, 회오리 베기.
- **바뀜:** 3인 파티 → 1인. 직업 5종 → 6종(강령술사 추가, 도적은 어쌔신 쪽). 듀오 카드 → 조합 카드. 동료 AI → 소환수 AI.
- **제거:** 예전 1인 총기 게임의 슈트 각인(카드로 통일).

## 11. 구현 나눔 (계획 단계에서 확정)

1. 원정을 1인으로: 원정 출발·귀환, 영혼 전송(귀환·신호기), 죽음 시 손실
