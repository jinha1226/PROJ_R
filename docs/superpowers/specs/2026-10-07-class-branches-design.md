# 직업 갈래와 연쇄 재편 설계 (계획 C3, 2026-10-07)

`2026-10-07-solo-soul-design.md`의 §3(판타지 직업)·§4(카드 = 기술)를 구체화하고 대체한다. 연쇄 엔진(조건 → 효과 → 그 효과가 다시 조건, 한 행동 12단계 상한, 행동마다 한 번·`반복` 표시는 여러 번), 태그 공명(3·6), 카드 종류(법칙·증폭·변환, 법칙은 강화)는 그대로 쓴다.

## 1. 목표

- **공격은 연쇄로 나간다.** 버튼으로 기술을 쓰는 게 아니라, 기본 공격·피격·대기·이동이 조건을 건드리고, 효과가 다음 효과를 불러 공격이 연쇄로 터져 나간다.
- **디아블로 2식 세부 빌드.** 직업마다 갈래 3개(예: 냉기 마법사, 뼈 강령술사)가 있고, 같은 직업도 갈래에 따라 전혀 다르게 논다.
- **영혼 둘을 넣으면 갈래끼리 물린다.** 직업이 남기는 결과물(상태이상, 시체, 처치)을 다른 직업 카드가 받아먹는다.

## 1.5 아르카식 연쇄 규칙 (2026-10-07, 사용자 결정)

효과의 출처(영혼 갈래·기억·장비·모듈·장신구)가 서로를 더 많이, 더 길게 건드리게 엔진 규칙을 바꾼다.

1. **발동 피해도 적중이다.** 카드·장비·고유 능력이 준 피해도 '적중 시(hit)'·'치명 시(crit)'·'처치 시(kill)' 조건을 건드린다. 다른 출처의 효과를 연달아 부른다.
   - 사건에는 `발동` 표시가 붙는다. 카드가 원하면 '기본 공격만'으로 조건을 좁힐 수 있다(예: 탄창 소모, 광란 중첩).
2. **자기 자신은 못 부른다.** 어떤 효과가 준 피해가 그 효과 자신을 다시 발동시키지는 않는다. 다른 출처는 부를 수 있다.
   - 같은 효과는 한 행동에 한 번이고, `반복` 표시가 있는 것만 여러 번 터진다(지금 규칙 유지).
3. **연쇄 상한 12 → 30.** 적이 많아지는 만큼 연쇄도 길게 간다. 화면에는 `연쇄 ×n`과 단계별 이펙트로 보인다.
4. **피해에 속성이 붙는다.** 물리·화염·냉기·번개·독·신성·뼈. 범용 조건 '○○ 피해를 줄 때마다'가 출처와 상관없이 발동한다.
5. **갈래마다 범용 카드 1장.** 갈래 4장 중 최소 1장은 공용 상태·사건(출혈 적이 죽음, 화상 피해를 줌, 시체가 터짐, 표식 적이 맞음 등)에 반응한다. 그래야 어떤 영혼·장비와 섞어도 서로 터진다.
6. **증폭은 곱한다.** 증폭 카드와 공명은 서로 더하지 않고 곱한다. 목표는 10층 이후 한 행동 총 피해가 1층의 20~50배이고, 봇으로 '행동당 피해'를 측정한다.

## 1.6 맵과 몬스터는 깊이에 따라 늘어난다

| 층 | 맵 크기 | 방 수 | 일반 방의 적 | 구성 |
|---|---|---|---|---|
| 1–2 | 64×64 | 16–22 | 3–5 | 졸개 위주 |
| 3–5 | 80×80 | 24–32 | 5–8 | 졸개 70% · 일반 25% · 정예 5% |
| 6–9 | 96×96 | 32–42 | 8–12 | 졸개 65% · 일반 25% · 정예 10% |
| 10–15 | 112×112 | 42–54 | 12–18 | 졸개 60% · 일반 28% · 정예 12% |

- **졸개:** 한두 대에 쓰러지는 약한 적(체력 낮음). 연쇄의 땔감이다. 처치 경험치와 자원은 적게 준다.
- **무리 단위:** 방의 적은 같이 깨어나는 무리라, 연쇄 한 번에 무리가 쓸려 나가는 장면이 나온다.
- **성능 점검:** 한 층에 적이 수백 마리가 될 수 있다. 깨어 있지 않은 무리는 계산을 쉬게 하고, 화면 밖 인물은 그리지 않거나 가벼운 모델로 바꾸는 최적화를 같은 작업에서 확인한다(휴대폰 기준 프레임).
- 수치는 봇으로 맞춘다(밸런스 작업은 C4).

## 2. 구조

### 2.1 직업마다 갈래 3개 × 카드 4장 = 12장

| 자리 | 역할 |
|---|---|
| 상징 | 그 갈래의 대표 조건 기술 (디아2 대표 스킬 오마주) |
| 법칙 | 상징의 재료를 만들거나 연쇄를 잇는다 |
| 변환 | 갈래의 결과물을 다른 것으로 바꾼다 (자주 `반복`으로 자기 고리를 만든다) |
| 증폭 | 그 갈래 태그 수만큼 강해진다 (디아2 시너지) |

- **연쇄 재료:** 갈래마다 하나씩 있다(화상, 냉기·빙결, 표식, 보호막, 함정, 기, 시체·소환수, 탄창 등). 갈래 안에 그 재료가 혼자 도는 고리가 최소 하나 있다.
- **태그:** 카드마다 갈래 태그가 붙는다. 공명(같은 태그 3·6장)으로 갈래 깊이에 보상이 붙는다.
- **고유 능력 2개 + 궁극기 1개:** 직업마다 둔다(아래 §4). 고유 능력은 모든 갈래에 공통인 바탕이다.

### 2.2 레벨업 카드 제시

3장 중 1장을 고르는 랜덤 방식은 유지하고, 빌드가 완성되도록 보완한다.

1. **첫 레벨업 = 갈래 고르기.** 첫 제시에는 넣은 영혼 직업들의 상징 카드만 나온다(영혼 하나면 상징 3장, 둘이면 6장 중 3장이되 직업마다 최소 1장).
2. **고른 갈래 우대.** 같은 갈래 카드는 3배, 가진 태그 카드는 2배로 자주 나온다. 상징을 가진 갈래의 카드가 매 제시에 최소 1장 들어간다(남아 있으면).
3. **다시 뽑기 판당 2번.** 제시 화면에 `다시 뽑기 n` 버튼을 둔다.
4. **섞이는 재미.** 3장 중 1장은 공통 카드나 다른 갈래 카드가 나올 수 있다. 영혼마다 최소 1장 규칙(C1), 학자 기억 +1장, 서약(10·14레벨)은 그대로다.

### 2.3 새 태그 5개와 공명

| 태그 | 3장 | 6장 |
|---|---|---|
| #뼈 | 전투 시작 뼈 조각 보호막 6 | 뼈 피해가 뒤의 적까지 관통 |
| #함정 | 함정 설치 수 +1 | 함정이 두 번 터진다 |
| #함성 | 기절·공포 지속 +1턴 | 함성 기술이 터질 때 보호막 10 |
| #오라 | 오라 범위 +1칸 | 오라 안의 적 노출 |
| #신성 | 신성 피해마다 체력 2 회복 | 신성 피해 10% 기절 |

기존 태그(화염·냉기·전기·독·출혈·근접·원거리·방패·은신·치유·소환·생존·치명)는 그대로다. 1인 체제라 #협공은 소환수·분신과의 협공으로 읽는다(§7).

## 3. 갈래와 카드 (7직업 × 12장)

표기: **상징**/법칙/변환/증폭 · `반복` = 한 행동 안에서 여러 번 터질 수 있음 · '/' 뒤는 강화(2단).

### 3.1 전사 (재료: 피격·분노·광란·출혈)

| 갈래 | 카드 | 효과 / 강화 |
|---|---|---|
| **회오리** #출혈 | **칼바람**(상징) | 회오리 베기 조건이 '피격 또는 처치 1회'로 완화, 회전마다 출혈 / 회전 범위 +1 |
| | 피의 소용돌이(법칙, 반복) | 출혈 중인 적이 죽음 → 그 자리에서 회오리 베기 한 번 / 피해 +30% |
| | 상처 찢기(변환) | 출혈 5중첩 → 터뜨려 중첩 × 6 피해 / 주변 1칸에도 |
| | 칼날 숙련(증폭) | #출혈 1당 회오리 베기 피해 +12% |
| **광란** #근접 | **광란**(상징) | 적중마다 광란 1(최대 5): 중첩당 공격 시간 −8%, 3턴 적중 없으면 초기화 / 최대 8 |
| | 연속 도륙(법칙, 반복) | 광란 5 이상에서 처치 → 즉시 한 번 더 공격 / 광란 3부터 |
| | 광폭화(변환) | 광란 중첩 1당 치명 확률 +5% |
| | 피의 광기(증폭) | #근접 1당 광란 중첩당 피해 +2% |
| **함성** #함성 | **전투 함성**(상징) | 전투 시작·위기 → 3칸 안 적 1턴 기절 + 도발 / 2턴 |
| | 분노 축적(법칙) | 피격마다 분노 1(최대 5) → 다음 공격 분노 × 30% 추가 / 터질 때 주변 1칸 분노 × 4 |
| | 철벽 반격(변환) | 반격 피해 +50%, 반격 25% → 기절 |
| | 함성 숙련(증폭) | #함성 1당 기절·도발 중인 적이 받는 피해 +10% |

- **고유 능력:** 회오리 베기(1턴 안 2회 피격 → 주변 4칸), 응수(막기 → 반격)
- **궁극기 대지 강타:** 지정 칸으로 도약해 내려찍고 주변 2칸 기절. 착지 순간 회오리 베기 한 번.
- **고리:** 출혈 적 처치 → 회오리 → 출혈 → 처치 → 회오리 … / 광란 처치 → 추가 공격 → 처치 …

### 3.2 마법사 (재료: 원소 상태·반응)

| 갈래 | 카드 | 효과 / 강화 |
|---|---|---|
| **화염** #화염 | **운석**(상징, 반복) | 화상 걸린 적이 죽음 → 그 자리에 운석(반경 1 피해·화상) / 운석 자리 2턴 불바다 |
| | 화염구(법칙) | 세 번째 공격마다 → 화염구(반경 1 폭발, 화상) / 두 번째마다 |
| | 화염 전이(변환) | 화상 피해로 죽음 → 주변 적 화상 2중첩 |
| | 화염 숙련(증폭) | #화염 1당 화상·운석 피해 +15% |
| **냉기** #냉기 | **블리자드**(상징) | 제자리 2턴(공격·대기) → 주변 2칸 2턴 눈보라(턴마다 냉기·피해) / 3칸 |
| | 서리 고리(법칙) | 피격 또는 처치 → 주변 2칸 냉기 + 1칸 밀침(턴당 1회) / 냉기 대신 빙결 |
| | 서리 감옥(변환) | 냉기 2번 → 빙결 / 빙결된 적이 죽으면 사방 2칸 냉기(반복) |
| | 냉기 숙련(증폭) | #냉기 1당 빙결된 적이 받는 피해 +12% |
| **번개** #전기 | **연쇄 번개**(상징) | 치명 → 번개가 적 사이 3번 튐(감전) / 5번 |
| | 정전기장(법칙) | 적중 → 3칸 안 모든 적에게 현재 체력 8% 피해(턴당 1회) / 12% |
| | 과전류(변환, 반복) | 감전된 적이 맞음 → 감전이 1칸 옆 적으로 옮겨감 |
| | 번개 숙련(증폭) | #전기 1당 감전·연쇄 번개 피해 +15% |

- **고유 능력:** 원소 순환(적중마다 화상 → 냉기 → 감전 순서로 부여, 기존 카드에서 승격), 파쇄(빙결된 적 2배)
  - 기존 '연쇄 주문'(세 번째 시전 화염구)은 화염 갈래 카드로 옮긴다.
- **궁극기 순간이동:** 지정 칸으로 이동하며 출발·도착 지점에 다음 원소 폭발(반경 1).
- **고리:** 운석이 화상 적을 죽임 → 운석 … / 빙결 적 처치 → 사방 냉기 → 빙결 → 처치 … / 감전 옮겨감 연쇄.
- **갈래 섞기:** 원소 순환 덕에 두 갈래를 섞으면 반응(증기·과부하·초전도)이 자연스럽게 난다.

### 3.4 성직자 (재료: 보호막·망치·오라)

| 갈래 | 카드 | 효과 / 강화 |

| | 신성 방벽(증폭) | #방패 1당 보호막 +15% |
| **오라** #오라 | **정화의 오라**(상징) | 매 턴 주변 2칸 적에게 신성 피해 3(+레벨) / 3칸 |

- **고유 능력:** 구원의 손(자신이나 소환수 위기 → 치유 22), 축복(전투 시작 → 자신·소환수 보호막)
- **궁극기 신성 결계:** 지정 범위(반경 2) 3턴 결계. 안의 아군은 무적이고, 적은 턴마다 신성 피해.
- **고리:** 처치 → 보호막 → 맞아서 깨짐 → 폭발 → 처치 → 보호막 … / 망치에 죽음 → 망치 추가 …

### 3.5 도적 (어쌔신, 재료: 함정·기·은신)

| 갈래 | 카드 | 효과 / 강화 |
|---|---|---|
| **함정** #함정 | **번개 함정**(상징) | 대기 → 2칸 안 빈칸에 번개 함정(밟으면 감전·피해, 3번 터짐) / 함정 2개 |

| | 마무리 일격(법칙) | 기 3 이상에서 공격 → 기를 모두 써 폭발(기당 피해 +50%, 주변 1칸) / 기절 |

- **고유 능력:** 배후 급소(나 말고 다른 대상(소환수·분신)을 노리는 적 → 1.6배), 잠행(처치 → 은신)
- **궁극기 그림자 분신:** 지정 칸에 분신 둘(3턴). 분신은 따로 생각하지 않고 내 공격을 자기 자리에서 따라 한다. 함정도 같이 깔고 기도 같이 쌓으며, 한 대 맞으면 사라진다.
- **고리:** 함정 연쇄 기폭 / 마무리 일격 처치 → 기 회복 → 마무리 … / 처치 → 은신 → 순간이동 공격 → 처치 …

### 3.6 강령술사 (새 기본 직업, 재료: 시체·소환수·독)

| 갈래 | 카드 | 효과 / 강화 |

| **뼈** #뼈 | **뼈 창**(상징) | 치명 → 일렬 관통 뼈 창 / 두 줄 |

| | 뼈 숙련(증폭) | #뼈 1당 뼈 피해 +12% |

| | 독 숙련(증폭) | #독 1당 중독 피해 +15% |

- **고유 능력:**
  - **시체 폭발**(반복): 처치 → 시체가 터져 주변 1칸에 대상 최대 체력 15% 피해. 모든 갈래의 공용 엔진이다.
  - **망자의 부름:** 처치 20% → 해골
- **궁극기 골렘:** 지정 칸 주변 시체를 모두 모아 골렘을 만든다. 시체 수만큼 크고, 불탄 시체면 화염, 언 시체면 냉기 골렘이 된다. 주변 적의 공격을 끌어당기고, 죽으면 거대한 시체로 대폭발한다(시체 폭발 연쇄의 점화 장치).
- **고리:** 처치 → 시체 폭발 → 처치 → 시체 폭발 … / 해골 소환 → 해골이 죽음 → 시체 2구 → 폭발 … / 중독 폭발 → 중독 확산 → 폭발 …
- **시체 규칙:** 쓰러진 적은 시체로 남는다(밟으면 지나갈 수 있음). 폭발, 해골, 골렘에 쓰인 시체는 사라진다.

## 5. 소환수와 분신

- **해골, 해골 궁수, 골렘:** 파티 AI(유틸리티 점수, 돌진, 대상 유지)를 쓴다. 해골은 10턴, 골렘은 죽을 때까지 간다.
- **그림자 분신:** AI가 없다. 내 공격·함정·기 쌓기를 자기 자리에서 따라 하는 복제다.
- **축복의 망치:** 나를 중심으로 도는 궤도 물체다(유닛 아님).
- 소환수 처치도 주인의 처치로 쳐서 주인의 '처치 →' 카드가 발동한다(시체 폭발 연쇄의 재료).

## 6. 정리할 것

- **삭제:** 상위 직업 9종(광전사·수호기사·저격수·사냥꾼·원소술사·심판관·치유사·암살자·독술사)과 그 고유 능력·궁극기·외형, 베테랑 흔적. 강령술사는 같은 id(`necromancer`)로 기본 직업(`BaseClass`)이 되고 상위 직업 시절의 고유 능력·궁극기(망자의 군세)는 §3.6으로 대체한다.
- **카드 정리:** 기존 직업 카드 중 갈래에 안 들어간 것은 공통 카드로 옮기거나 지운다. 가시 갑옷, 최후의 버팀, 피의 대가, 처형, 상처 벌리기, 배신의 칼날, 독화살, 가시 덫, 구르며 쏘기, 응답하는 기도, 축복 확산, 순교, 원소 과부하, 마력 역류, 반응 증폭, 연쇄 반응, 번개 사슬, 원소 순환(고유 능력으로 승격)이 대상이다.
- **공통 카드:** 아군을 전제한 카드(결속, 사기, 협공 공명)는 소환수·분신을 아군으로 읽게 고친다.
