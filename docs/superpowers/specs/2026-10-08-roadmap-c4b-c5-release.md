# 남은 로드맵: C4b ~ C8 (출시까지) (2026-10-08)

상태: 정리 문서. C4a(기지 모드·흘러오는 습격·방어 강화)까지 끝난 시점에서, 남은 일을 계획으로 쪼개기 전에 모아 둔다. 각 단계는 시작할 때 이 문서를 바탕으로 스펙(필요하면)과 구현 계획을 쓴다.

- 1인 원정: 빈 몸(SF) + 영혼 6직업, 직업마다 갈래 3개 × 카드 4장(상징·법칙 3단, 변환·증폭 2단), 조합 카드 15장, 궁극기 7종(모두 칸 지정)
- 던전: 깊이별 맵·밀도, 아르카식 연쇄, 영혼석 미감정, 귀환 신호기
- 지상: 기지 모드(자유 카메라, 건물 패널, 거점 메뉴), 작업장, 클론 생성·영혼 주입
- 습격: 실시간 진행, 지휘·직접 조종·궁극기 바, 포탑처럼 자리 지키기, 자유 좌표 대군 60~150, 방어 시설 3단계, 함선 지원, 부상·수리

## C4b: 첫 임무와 밸런스

**목표:** 처음 켠 사람이 막히지 않고 게임의 고리(던전 → 귀환 → 기지 → 습격)를 한 바퀴 돌게 하고, 숫자를 봇과 손으로 맞춘다.

1. **첫 임무 흐름** (스펙 `2026-10-07-solo-soul-design.md`의 첫 임무 절)
   - 빈 몸으로 1층 → 첫 영혼석·자원 → 귀환 신호기로 귀환 → 기지 업그레이드 → 1층 클리어 → 영혼 주입 안내
   - 기지 모드 전환 뒤 손이 닿지 않게 된 지상의 영혼석·진지 정리(지상 탐험이 없으므로 처음 영혼은 던전에서)
   - 짧은 안내 문구(설명형 UI 문구 금지 규칙 안에서, 무엇을 누를지만)
2. **밸런스**
   - 던전: 깊이별 폭딜 성장(목표 1층 대비 깊은 층 20~50배, 지금 2~3배), 빈 몸·원거리 조합(봇 평균 도달 층: 빈 몸 1.95, 마법사/궁수 2.5 vs 전사/성직자 4.9)
   - 카드 3단 효과 수치, 증폭 배율
   - 습격: 규모 공식, 졸개 체력·피해, 방어력 대 규모 자동 방어 기준(지금은 너무 쉽게 넘음), 처치 보상
   - 벽 부수는 비용(지금 8): 림월드식 길목 유도가 의미 있게
   - 업그레이드·수리·함선 지원 비용
3. **C4a에서 미룬 작은 것들**
   - 졸개 계산의 건물 조회 비용(셀 → 건물 색인), 엘리트 경로의 맵 복사
   - 지상 화면을 다시 열 때 쌓이는 창 이벤트 리스너
   - 조정 페이지 저장 엔드포인트 경로·크기 제한
   - 직접 조종을 풀 때 카메라 튐, 습격 마지막 순간 처치의 생체·경험치 누락
   - 터치 직접 조종(지금 없음)

## C5: 이펙트와 연출

**목표:** 연쇄가 터질 때마다 눈에 보이게. 기존 메모(연쇄는 동시에 겹쳐 터지고, 연쇄 효과마다 자기 VFX)를 따른다.

1. **이펙트 키트:** 프로스트 노바·블리자드 지속 눈보라·회오리(칼바람 회전)·축복의 망치 궤도·정화의 오라 고리·번개 함정과 화염 함정 표시(지금은 깔 때만 번쩍임)·그림자 분신·골렘·운석·연쇄 번개
2. **습격 연출:** 졸개 처치 먼지·파편, 포탑 사격, 전기 지뢰, 궤도 포격(하늘에서 떨어지는 빔), 궤도 레이저(직선 빔), 포드 피격, 물결 등장 예고
3. **기지 연출:** 클론의 일하는 동작(땅 정리·줍기·쉬기), 건물 파손·수리 모습
4. **갈래 데모 기반 작업:** `?demo=branch`의 21개 갈래를 보면서 연쇄별 VFX를 정하고 붙인다
5. **화면 다듬기:** 결과 창·패널의 터미널 스타일 통일, 휴대폰 배치

## C6: 저장과 엔딩 (한 판이 끝까지 돌게)

**목표:** 브라우저를 닫아도 이어서 하고, 판이 엔딩으로 끝난다. 이게 있어야 C4b 밸런스를 처음부터 끝까지 잴 수 있다.

1. **저장·불러오기** (지금: 없음, 화면 설정만 `gridPreferences.ts`가 저장)
   - 판 진행 저장: 지상(포드·건물·단계·파손), 클론(몸·영혼·레벨·카드·부상), 영혼석 보관함, 자원, 작업장(설계도·모듈), 습격 일정·횟수, 원정 기록(최고 층)
   - 저장 시점: 귀환·습격 종료·기지 모드 진입 때 자동, 던전 안은 층 진입 때(층 중간 저장은 안 함)
   - 타이틀에 '이어하기', 저장 버전 번호 + 손상·구버전이면 버리지 않고 알림
2. **엔딩** (지금: 스펙만, `2026-10-06-base-raids-design.md` §9)
   - 정복: 15층 마왕 처치(마왕전 패턴 포함)
   - 탈출: 우주선 수리 완료 + 최종 습격 버티기
   - 엔딩 화면과 판 기록(걸린 날·클론·영혼·최고 층), 새 판

## C7: 사운드와 에셋

1. **사운드** (지금: 코드·파일 모두 없음)
   - 소리 엔진(WebAudio, 동시 재생 제한, 대군 처치음 묶기)
   - 효과음: 타격·총·화살·마법 원소별·폭발·함정·궁극기·UI·포드·습격 경보
   - 배경음: 던전 층대 3구간·기지·습격·마왕전
   - 볼륨(전체·효과음·배경음) 설정
2. **에셋**
   - 무기 장착 위치·체형: `?demo=tune`으로 맞춘 값 반영
   - 클론·적 외형 정리(직업별 구분), 마왕군 졸개·정예·장군 구분
   - 건물·포드·방어 시설 모델 통일, 아이콘
