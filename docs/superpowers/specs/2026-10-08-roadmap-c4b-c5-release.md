## C4b: 첫 임무와 밸런스

**목표:** 처음 켠 사람이 막히지 않고 게임의 고리(던전 → 귀환 → 기지 → 습격)를 한 바퀴 돌게 하고, 숫자를 봇과 손으로 맞춘다.

1. **첫 임무 흐름** (스펙 `2026-10-07-solo-soul-design.md`의 첫 임무 절)
   - 빈 몸으로 1층 → 첫 영혼석·자원 → 귀환 신호기로 귀환 → 기지 업그레이드 → 1층 클리어 → 영혼 주입 안내
   - 기지 모드 전환 뒤 손이 닿지 않게 된 지상의 영혼석·진지 정리(지상 탐험이 없으므로 처음 영혼은 던전에서)
   - 짧은 안내 문구(설명형 UI 문구 금지 규칙 안에서, 무엇을 누를지만)
2. **밸런스**
   - 던전: 깊이별 폭딜 성장(목표 1층 대비 깊은 층 20~50배, 지금 2~3배), 빈 몸·원거리 조합(봇 평균 도달 층: 빈 몸 1.95, 마법사/궁수 2.5 vs 전사/성직자 4.9)
   - 카드 3단 효과 수치, 증폭 배율
   - 습격: 규모 공식, 졸개 체력·피해, 방어력 대 규모 자동 방어 기준(지금은 너무 쉽게 넘음), 처치 보상
   - 벽 부수는 비용(지금 8): 림월드식 길목 유도가 의미 있게
   - 업그레이드·수리·함선 지원 비용
3. **C4a에서 미룬 작은 것들**
   - 졸개 계산의 건물 조회 비용(셀 → 건물 색인), 엘리트 경로의 맵 복사
   - 지상 화면을 다시 열 때 쌓이는 창 이벤트 리스너
   - 조정 페이지 저장 엔드포인트 경로·크기 제한
   - 직접 조종을 풀 때 카메라 튐, 습격 마지막 순간 처치의 생체·경험치 누락
   - 터치 직접 조종(지금 없음)

## C5: 이펙트와 연출

**목표:** 연쇄가 터질 때마다 눈에 보이게. 기존 메모(연쇄는 동시에 겹쳐 터지고, 연쇄 효과마다 자기 VFX)를 따른다.

1. **이펙트 키트:** 프로스트 노바·블리자드 지속 눈보라·회오리(칼바람 회전)·축복의 망치 궤도·정화의 오라 고리·번개 함정과 화염 함정 표시(지금은 깔 때만 번쩍임)·그림자 분신·골렘·운석·연쇄 번개
2. **습격 연출:** 졸개 처치 먼지·파편, 포탑 사격, 전기 지뢰, 궤도 포격(하늘에서 떨어지는 빔), 궤도 레이저(직선 빔), 포드 피격, 물결 등장 예고
3. **기지 연출:** 클론의 일하는 동작(땅 정리·줍기·쉬기), 건물 파손·수리 모습
4. **갈래 데모 기반 작업:** `?demo=branch`의 21개 갈래를 보면서 연쇄별 VFX를 정하고 붙인다
5. **화면 다듬기:** 결과 창·패널의 터미널 스타일 통일, 휴대폰 배치
