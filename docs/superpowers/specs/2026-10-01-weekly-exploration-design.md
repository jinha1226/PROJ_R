# 설계 개정 — 주간 진행 · 탐험 맵 · 직접 조작 · 아이소메트릭 전투

작성일: 2026-10-01
상태: 승인됨(대화 승인). 기존 설계서 `2026-10-01-mercenary-roguelike-design.md`의 **5장(런 구조)을 대체**하고, 6.3(전투 연출)의 카메라·배치를 개정한다. 나머지(전투 규칙·성격·관계·성장)는 그대로 유효하다.

## 1. 개정 이유
- 단계 지도는 "한 파티가 던전을 통과하는" 리듬이라 용병단 판타지와 다음 마일스톤(여러 파티·자동 탐험)으로 확장하기 어렵다.
- 주 단위는 성장(훈련)·관계(휴식)·영입(방문)을 플레이어의 주간 결정으로 만든다.
- 현재 버전은 지나치게 어렵다(적 단계당 +8%·최대 7명, 낮은 경험치, 보스 체력 약 3000). 새 구조 기준으로 밸런스를 다시 잡는다.

## 2. 주간 진행
- 한 판 = **12주**. **12주차에 잿빛 기사 습격**(보스전 강제). 화면에 "습격까지 N주" 상시 표시.
- **주 시작**: 영입 방문(60%, 2주차 확정, 후보 1~2명, 비용 규칙은 기존과 동일) → 주 시작 사건(25%, 기존 사건 8종 재사용).
- **이번 주 행동 1개 선택**
  - **탐험**: 지역 카드 3장 중 선택 → 탐험 맵(3장).
  - **훈련**: 선택한 최대 5명이 위험 없이 경험치(각자 다음 레벨 필요량의 40%) 획득. 25% 확률 훈련 사건(대련 등).
  - **휴식**: 전원 부상 회복 + 두 명 대화(친밀도 +12, 수다쟁이 +15). 25% 확률 관계 사건.
- 출전하지 않은 인원은 그 주에 자동으로 쉰다(부상 −1).
- **주 마감 보고**: 이번 주의 순간들·성장·관계 변화.
- 상점: 노드가 아니라 **용병단 화면에서 상시**(주 1회 재고 갱신).
- 런 실패: 주인공 사망, 전원 사망, 보스전 패배. 성공: 보스 처치 → 용병단 이름 → 명예의 전당.
- 저장: 주 시작·행동 확정·탐험 방 이동·전투 시작/종료마다 자동 저장. **저장 형식 v2**(구 저장은 폐기).

## 3. 탐험
### 3.1 지역 카드
- 카드: 테마, 난이도 ★1~3, 보상 경향(골드/장비/경험치), 예상 방 수.
- 적 단계 = 주차 + (★ − 1). 적 수 = min(6, 1 + ★ + ⌈주차/3⌉).

### 3.2 테마
| 테마 | 적 | 장식(에셋) | 고유 사건 |
|---|---|---|---|
| 숲 | 산적 위주 | KayKit Medieval Hexagon nature(나무·바위·덤불) | 사냥꾼 흔적 |
| 던전 | 해골 위주 | KayKit Dungeon Remastered(벽·기둥·횃불·상자·통) | 함정 |
| 묘지 | 해골·주술사 | KayKit Halloween Bits(묘비·철책·고목·지하묘지) | 무덤 도굴 |

### 3.3 탐험 맵(구역형)
- 방 6~10개, 격자 위 절차 생성(신장 트리 + 고리 1~2개). 방 크기 = 전투장 크기(24×14m), 방 사이 통로.
- 방 종류: 시작, 적 무리(가시적으로 서 있음), 정예(시작에서 먼 방), 보물상자, 사건, 모닥불(1회, HP·부상 소량 회복), 출구.
- 전장의 안개: 미방문 방은 어둡게. 인접 방 실루엣은 보인다.
- **적 무리 방에 들어서면 그 방이 전장**: 방 장식이 엄폐물, 아군은 **들어온 문 쪽에서 진형대로** 시작, 적은 **방에 서 있던 위치**에서 시작. 전투 직전 진형 확인·수정 가능.
- 출구 도달 또는 언제든 `귀환` → 얻은 보상 유지, 탐험 종료(= 그 주 종료). 전투 패배 = 후퇴(참전자 부상, 골드 30% 손실), 탐험 즉시 종료.
- 탐험 중 부상·쓰러짐은 탐험이 끝날 때까지 이어진다.

## 4. 조작
- **탐험**: 주인공을 직접 이동(동료는 줄지어 따라옴), 카메라 추적.
  - 조이패드(Gamepad API): 왼쪽 스틱 이동, A 상호작용/확인, B 취소, LB/RB 카메라 90° 회전, Start 메뉴.
  - 키보드: WASD/방향키 이동, E 상호작용, Esc 메뉴, Z/X 카메라 회전.
- **전투**: 기본 자동. 버튼(조이패드 Select/키보드 Tab)으로 **주인공 직접 조작** 켜기/끄기(Plan 6).
  - 왼쪽 스틱 이동, A 기본 공격(앞쪽 가까운 적 자동 조준), X·Y 액티브, RB 궁극기. 나머지 동료는 자동.
  - 입력은 "틱 N의 명령"으로 시뮬레이션에 전달(결정론 유지).
- 밸런스는 자동 전투 기준.

## 5. 전투 시점(6.3 개정)
- 카메라: **아이소메트릭**(방위 45°, 고도 약 40°), 90° 단위 회전. 기존 수동 팬·줌·자동 추적 유지.
- 배치: 샌드박스는 기존 3×4 대치 유지. 탐험 전투는 3.3의 방향성 배치(진입 방향 기준으로 진형 회전).

## 6. 밸런스 목표(헤드리스 시뮬레이션으로 검증)
- 12주차 주력 5명 평균 레벨 7~8.
- 승률(권장 성장 파티, 자동): ★1 ≥ 85%, ★2 65~75%, ★3 45~55%, 보스 55~70%.
- 출발점 조정: 적 단계 성장 8% → 6%/단계, 적 수 상한 6, 경험치 = 참전 30 + 처치 6 + 승리 20, 보스 체력은 목표 승률에 맞춰 결정.

## 7. 구현 분할
- **Plan 5**: 주간 구조, 탐험 맵(생성·3D 렌더·이동·조이패드·안개), 테마 3종 에셋, 방 전투(방향성 배치·방 장식 엄폐물), 아이소메트릭 카메라, 밸런스 패스.
- **Plan 6**: 전투 중 선택적 직접 조작, 연출·사운드 마감, 전체 런 E2E.
