# 메타 루프 핵심 — 설계서 (하위 프로젝트 1)

상태: 설계(2026-10-03). 상위 개요: `2026-10-03-meta-structure-design.md`(2차). 기존 시스템: `2026-10-03-grid-roguelike-systems-design.md` — 겹치는 부분은 이 문서가 우선한다.

## 0. 결정 기록 (사용자, 2026-10-03)

- 15층 = **동굴(1~5) → 지하 묘지(6~10) → 고대 유적(11~15)**. 5·10층 끝 구간 보스, 15층 에너지원 + 최종 수호자.
- **중단 저장 + 구간 지름길**: 판 도중 종료하면 그 자리에서 이어하기(되돌리기 없음). 구간 보스를 처음 잡으면 기지에서 6층·11층 출발을 해금(대신 시작 각인 없이 기본 장비).
- **직업 없음**: 무기고에서 해금한 **시작 총**으로 출발.
- 우주선은 이번엔 메뉴 화면. SF 에셋은 하위 프로젝트 3.
- **슈트 각인**(약 6칸), 손에 든 무기 종류로 발동. **각인 레벨 없음**.
- **흡수**: 정예 적 처치 → 그 적 계열 각인 3지선다.
- **총은 슈트 충전량**을 쓴다. 근접 공격·처치로 충전.
- **활·석궁·투척 단검 삭제**(투척은 추천 수용, 이의 시 복구). 원거리 = 총, 마법 = 현지 원소 지팡이, 근접 = 현지 근접 5종.
- **레벨업 = 슈트 강화 3지선다**(새 각인은 흡수로만).
- 죽은 층의 슈트는 이번 단계에서 **(가) 선택 보너스**: 회수하면 각인이 시작 각인 후보로 전송된다. (나) 얼터 재료 여부는 하위 프로젝트 2에서 다시 본다.

## 1. 판 구조

| 구간 | 층 | 이번 단계의 모습 | 보스 |
|---|---|---|---|
| 동굴 | 1~5 | 지금 던전 키트 + 동굴 색감(어두운 흙빛·푸른 이끼 조명), 횃불 적게 | 5층: 강화된 챔피언(기존 보스 재사용) |
| 지하 묘지 | 6~10 | 지금 모습 그대로 | 10층: 챔피언 + 소환 강화 |
| 고대 유적 | 11~15 | 지금 키트 + 유적 색감(창백한 돌·금빛 조명) | 15층: 최종 수호자(챔피언 최강판) + 에너지원 |

- 각 층은 지금 `generateMap`(48×48, 방·통로·함정·통·상자)으로 만든다. 계단은 1~14층, 보스 층(5·10)은 보스를 쓰러뜨리면 계단이 열린다.
- 적 출현 비율은 구간별 표로(동굴: 구울·졸개 많음, 묘지: 지금 비율, 유적: 전사·마법사·궁수 많음). 강해지는 곡선은 15층에 맞게 다시 잡는다(지금의 층당 +25%는 15층에서 너무 가파르다 → 층당 +12% 정도에서 시작, 밸런스 봇으로 조정).
- **승리**: 15층 수호자를 쓰러뜨리고 에너지원을 집으면 즉시 귀환 연출 → 1차 엔딩 화면(기록·에너지 정산).
- **지름길**: 항법실에서 해금하면 출격할 때 1·6·11층 중 고른다. 6·11층 출발은 시작 각인 없음, 레벨은 그 층에 맞는 값(예: 6층 = 레벨 4, 11층 = 레벨 7)으로 보정, 기본 슈트 강화 없음.

## 2. 무기

- **총(우주선 장비, 새 무기군)** — 슈트 충전량을 쓴다.

| 총 | 시간 | 피해(기준) | 사거리 | 충전 | 특징 |
|---|---|---|---|---|---|
| 권총 | 0.8 | 4~6 | 7 | 1 | 기본 지급 |
| 산탄총 | 1.0 | 5~8 (부채꼴 3칸) | 4 | 2 | 맞은 적 한 칸 밀치기 |
| 소총 | 1.2 | 8~12 | 9 | 2 | 엄폐 보정 절반 |

- **슈트 충전량**: 최대 10에서 시작. 근접 타격 +1, 근접 처치 +2. 판 시작 때 가득. 충전이 모자라면 쏠 수 없다(쏘기 버튼에 남은 충전 표시).
- **현지 무기**: 근접 5종(단검·장검·도끼·창·철퇴) 그대로, **원소 지팡이** 그대로(충전 횟수, 8턴마다 회복). 활·석궁·투척 단검과 화살 자원은 삭제.
- 손 2칸: 출발 때 손1 = 시작 총, 손2 = 비어 있음. 근접 무기·지팡이는 던전에서 줍는다. 시작 방 무기 거치대(시험용)는 삭제.
- 총 장비는 던전에서 떨어지지 않는다(우주선 장비 — 무기고 해금으로만).
- 기존 무기 등급(1·2) 체계는 현지 무기에 그대로. 장비 성장(등급 3·강화·저주)은 별도 단계.

## 3. 슈트 각인

- 무기의 각인을 없애고 **슈트에 6칸**. 칸이 차면 새 각인을 얻을 때 **교체할 칸을 고른다**(넘기기 가능).
- 발동 조건: 근접 각인 = 근접 무기를 들었을 때 / 사격 각인 = 총을 들었을 때 / 마법 각인 = 지팡이를 들었을 때 / 공용 = 언제나.
  - 기존 20종 그대로 쓰되 원거리 각인은 총 기준으로 다시 읽는다: 원소 화살 → **원소 탄**(지팡이 원소가 다음 총탄에), 밀치고 쏘기 → 다른 손의 총으로, 칼바꿈·연환은 교체 대상 무기가 아니라 "교체한 뒤 든 무기"의 종류로 발동.
- **각인 레벨 없음**. 이미 가진 각인은 흡수 선택지에 나오지 않는다.
- 룬석·`inscribe` 행동·룬 대장간 개념 삭제.
- **판이 끝나면 슈트 각인 초기화**. 시작 각인(§5)만 들고 출발.

## 4. 흡수와 기록

- **정예 적**: 층마다 1~2마리(보스 층 제외), 기존 적 종류의 강화판(체력·피해 ×1.6, 빛나는 테두리, 이름 앞에 "정예"). 처치하면 그 자리에 **잔향**이 남는다(걸어 들어가면 흡수, 1턴).
- 흡수하면 **그 적 계열**의 각인 3개 중 하나를 고른다(레벨업 3지선다 화면 재사용):
  - 졸개·전사 → 근접 계열 / 궁수 → 사격 계열 / 마법사 → 마법 계열 / 구울 → 공용 계열 / 보스 → 모든 계열에서.
- 3개 구성 = **기록된 각인 2개 + 아직 기록되지 않은 각인 1개**(발견 칸). 기록된 것이 모자라면 미기록으로 채우고, 모두 기록됐으면 3개 다 기록된 것. 이미 슈트에 있는 각인은 빠진다.
- **기록**: 처음 흡수한 각인은 기록된다(판이 끝나도 남음). 기록이 늘수록 다음 판의 정예 선택지가 안정된다. 처음부터 계열마다 1개씩 기록(돌진 베기·연사·연쇄 번개·기세).
- 기록 보관소에서 기록된 각인 목록을 본다.

## 5. 죽음과 슈트

- 죽으면 우주선 복제실에서 깨어난다(**무료**, 에너지 부족으로 막히는 일 없게).
- 슈트(그 판의 각인 전부)가 **죽은 층에 남는다**: 가장 최근 것 하나만. 다음 판의 같은 층(맵은 새로 생성) 계단에서 먼 방에 놓이고, **살해자의 잔향**(나를 죽인 적 종류의 정예판, 보스였다면 보스 그대로)이 지킨다. 함정·환경 피해로 죽었으면 그 층 정예 하나가 지킨다.
- 슈트에 닿으면(1턴) 그 각인들이 기지로 전송되어 **시작 각인 후보**가 된다(기존 후보를 대체). 회수 전에 또 죽으면 이전 슈트는 사라진다.
- 출격할 때 시작 각인 후보 중 **슈트 공방 칸 수**(1 → 최대 3)만큼 골라 들고 간다(1층 출발일 때만).

## 6. 에너지와 기지

- **에너지**: 처치마다 즉시 전송. `기본값 × (1 + 0.15 × (층 − 1))`, 기본값 = 졸개 2 · 구울 3 · 궁수 3 · 전사 4 · 마법사 4, 정예 ×3, 구간 보스 60 · 최종 수호자 150. 죽어도 남는다. 화면: 처치한 자리에서 위로 솟는 전송 광선 + 상단 에너지 수치.
- **시설**(초기 비용 — 밸런스 봇·시험으로 조정):

| 시설 | 단계 | 비용 | 효과 |
|---|---|---|---|
| 복제실 | 기본 | — | 부활(하위 프로젝트 2에서 얼터 생성) |
| 무기고 | 산탄총 / 소총 | 80 / 120 | 시작 총 해금·선택 |
| 슈트 공방 | 시작 각인 칸 2 / 3 | 100 / 250 | 출격 때 들고 가는 시작 각인 수 |
| 슈트 공방 | 충전 최대치 +2 (2회) | 60 / 140 | 시작 충전 최대치 |
| 기록 보관소 | 기본 | — | 기록된 각인 열람 |
| 항법실 | 6층 / 11층 지름길 | 150 / 300 | 구간 보스를 한 번 잡아야 구매 가능 |

- **레벨업 = 슈트 강화 3지선다**(판 안에서만): 충전 최대치 +2, 체력 +5(최대·현재), 근접 처치 충전 +1, 회피 +3%p, 총 피해 +1, 근접 피해 +1 — 판마다 무작위 3개. 경험치 곡선은 15층에 맞게 늘린다.

## 7. 우주선 화면 (메뉴)

- 타이틀 → `격자 출격` → **우주선 화면**: 에너지 잔량, 시설 카드(단계·비용·구매), 출격 패널(시작 총 · 출발 층 · 시작 각인 고르기), 기록 보관소 보기, 슈트 위치 표시("7층에 슈트가 남아 있다").
- 시설을 살 때마다 해당 구역이 밝아지는 간단한 연출.
- 판이 끝나면(사망·승리) 정산 화면 → 우주선 화면.

## 8. 저장

- **기지 저장**(`projr.grid.meta.v1`): 에너지, 시설 단계, 기록된 각인, 시작 각인 후보, 남은 슈트(층·각인·살해자 종류), 해금한 총, 최고 도달 층·승리 수. 기존 `projr.grid.v1`(최고 기록·승리 수)은 처음 불러올 때 옮긴다.
- **판 저장**(`projr.grid.run.v1`): 행동마다 판 상태(GridState 직렬화 — Set·Uint8Array 변환)를 저장. 우주선 화면에 "이어하기". 판이 끝나면 지운다.
- 시뮬레이션은 결정적이므로 저장/불러오기 왕복 테스트(같은 행동 → 같은 결과)를 둔다.

## 9. 없애는 것

직업(전사·사냥꾼·마법사)과 `CLASS_BONUS`, 활·석궁·투척 단검·화살, 무기 각인·룬석·`inscribe`, 각인 레벨, 시작 방 무기 거치대, 직업 선택 화면. 관련 테스트는 새 규칙으로 바꾸거나 지운다.

## 10. 이번 단계에서 하지 않는 것

얼터(동료)·관계, SF 에셋(우주선은 메뉴), 동굴·유적 전용 에셋과 새 적, 새 보스 디자인, PC 화면 개편, 장비 성장(등급 3·강화·저주).

## 11. 테스트

- 판 구조: 15층 진행, 보스 층 계단 잠금/해제, 구간별 출현 표, 15층 승리.
- 총: 충전 소모·부족 시 불가, 근접 타격/처치 충전, 산탄총 부채꼴·밀치기, 소총 엄폐 보정.
- 슈트 각인: 무기 종류별 발동, 6칸 교체, 이미 가진 각인 제외, 기존 각인 20종 회귀(총 기준으로 다시 읽은 것 포함).
- 흡수: 정예 생성 수, 잔향 → 계열 3지선다, 기록 2 + 발견 1 구성, 기록 유지.
- 죽음과 슈트: 슈트 배치·잔향 수호자·회수 → 시작 각인 후보, 하나만 남음.
- 에너지: 공식, 사망 후 유지, 시설 구매·잠금 조건, 지름길 출발 보정.
- 저장: 기지/판 왕복, 이전 기록 이전, 이어하기 결정성.
- e2e: 우주선 화면 → 출격 → 처치로 에너지 증가 → 사망 → 우주선 화면에 에너지·슈트 위치, 시설 구매.
- 밸런스 봇(이후): 15층 생존 곡선.
