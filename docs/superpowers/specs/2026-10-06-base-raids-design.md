# 2단계: 거점 · 습격 · 자동화 설계 (초안)

상태: 초안 (2026-10-06). 사용자 결정을 모았다. 바탕: `2026-10-06-soulbound-colony-design.md`, `2026-10-06-trigger-traits-design.md`.

## 0. 원칙: 좋아하는 건 깊게, 아닌 건 쉽게

모든 활동에 **"전투력" 하나로 판단하는 자동 길**과 **직접 길**을 둔다. 자동은 무난한 결과, 직접은 최적의 결과를 준다. 좋아하는 부분은 파고들고, 아닌 부분은 전투력을 올려 자동으로 넘긴다.

| 영역 | 자동 | 직접 |
|---|---|---|
| 던전 (탐험 + 전투) | **자동 원정**: 층의 적정 전투력 이상이면 무난히 클리어 | 직접 탐험, 턴제 지휘 |
| 빌드 (장비 + 특성) | **빌드 자동화**: 목표 상위 직업만 고르면 특성 선택·장비 착용·희생을 자동으로 | 태그 시너지 직접 설계 |
| 거점 건설 | **추천 배치**: 가진 광석 안에서 기본 틀을 한 번에 | 위치 직접 설계 |
| 습격 방어 | **자동 방어**: 방어력이 습격보다 높으면 빠르게 감아 결과만 | 직접 지휘 |
| 일꾼 | 놀면 주변 정리(애니메이션) | — |

## 1. 전투력

- **파티 전투력** = 살아 있는 클론마다 (레벨, 장비 수치, 특성 수, 전직 여부)로 계산해 합산한다. 공식은 봇 결과에 맞춰 조정한다.
- **층 적정 전투력:** 그 층을 자동 원정으로 무난히(봇 기준 클리어율 80% 이상) 깰 수 있는 파티 전투력.
- **방어력** = 방어 건물(망루 화력, 성벽 체력) + 거점에 있는 파티 전투력.
- **습격 규모:** 습격 예고 때 공개한다.
- 화면: 시추공을 내려가기 전에 "파티 전투력 / 이 층 적정"을, 습격 예고 때 "방어력 / 습격 규모"를 보여 준다.

## 2. 자동 원정

- 시추공에서 **자동 원정**을 고르면 봇이 탐험·전투·상자·광맥·계단을 진행한다. 빠르게 감아서 보여 준다.
- 멈추는 경우: 클론이 위험해질 때, 영웅 묘실을 만났을 때, 장군의 방 앞, 플레이어가 끊을 때. 언제든 직접 조작으로 넘어간다.
- 목표 깊이를 정해 두면 거기까지 내려갔다가 승강기로 돌아온다.
- 구현: 밸런스 봇의 탐험 정책(`tests/bot/delveBot.bot.ts`)을 게임 코드로 옮긴다.

## 3. 빌드 자동화

- 클론마다 **목표 상위 직업**(빌드 방향)을 고른다. 고르지 않으면 직업의 첫 번째 상위 직업.
- 레벨업 카드는 목표 태그에 가까운 것을 자동 선택한다.
- 새 장비를 주우면 숙련 무기이고 목표 태그가 더 맞는 것을 자동 착용하고, 남는 같은 칸 장비는 자동으로 희생한다.
- 클론별 "자동" 끄기 가능.

## 4. 거점

- 포드 주변의 **우리 영역**(되찾은 땅) 안에만 짓는다.
- **지상 진지는 없앤다.** 습격은 맵 가장자리에서 온다. 영역은 시설(망루 등)을 지으면 그 주변으로 조금씩 넓어진다.
- **혼합형 건설:** 시설은 건물 단위로 정해진 크기를 놓고, 방어물은 타일 단위로 끌어서 깐다. 재료를 내면 즉시 완료된다.

| 이름 | 크기 | 역할 | 비용 (예시) |
|---|---|---|---|
| 복제 포드 | 포드 자체 | 업그레이드: 동시에 깨울 클론 3 → 4 → 5 | 마정석 |
| 시추기 | 이미 있음 | 업그레이드: 시작 깊이 선택지 1 → 3 → 5 → 8층 | 광석 + 마정석 |
| 영혼 보관소 | 2×2 | 몸 없이 영혼석 보관, 원정마다 데려갈 클론 명단 | 광석 |
| 대장간 | 2×2 | 장비 희생 효율 상승, 수리 | 광석 |
| 의무실 | 2×2 | 귀환하면 파티 완전 회복 | 광석 + 생체 재료 |
| 창고 | 2×2 | 가방 밖에 장비 보관 | 광석 |
| 망루 | 1×1 | 사거리 6 안의 습격자 자동 사격, 주변 영역 확장 | 광석 |
| 성벽 | 타일 | 길을 막음. 습격자는 부수고 지나감 | 광석 1 |
| 방책 | 타일 | 엄폐물 | 광석 1 |
| 성문 | 타일 | 우리 편만 통과 | 광석 |
| 가시 함정 | 타일 | 밟은 습격자에게 피해 | 광석 |

- **일꾼 클론:** 영혼이 없는 클론(생체 재료로 출력)은 싸우지 못하고, 거점에서 놀 때 주변을 정리하는 애니메이션을 한다(도끼질, 곡괭이질, 줍기). 영혼석을 얻으면 일꾼에게 깃들여 전투 클론으로 바꿀 수 있다.
- **추천 배치:** 가진 광석 안에서 포드를 두르는 성벽 고리, 성문 2개, 망루를 기본 틀로 한 번에 깐다.

## 5. 습격

- **레퍼런스:** 게임플레이는 **쓰론폴**(단순한 건설 + 영웅이 직접 싸우며 탑·벽과 함께 막음)과 **돔키퍼**(캐러 내려갔다 습격 전에 돌아옴). 기술은 오픈소스 **민더스트리**(벽을 부수며 오는 길 찾기, 웨이브 구성, 탑 사격)를 참고한다.
- **시점:** 시추기를 처음 업그레이드했을 때, 또는 원정 4번째 중 먼저 오는 쪽부터 습격 시계가 돈다. 그 뒤로 **원정 2번마다** 귀환하면 습격이 온다. 그 전 귀환 때 예고한다.
- **규모:** 습격 횟수와 내려간 최대 깊이에 따라 커진다.
- **전투:** 지하와 같은 규칙(턴제·실시간). 습격자는 클론과 건물을 모두 공격하고, 성벽에 막히면 부수고, 포드를 가장 먼저 노린다. 건물에는 체력이 있고 습격 뒤 광석으로 수리한다.
- **자동 방어:** 방어력이 습격 규모보다 높으면 빠르게 감아 결과만 본다. 아니면 직접 지휘한다.
- **지면:** 포드가 부서지면 저장해 둔 재료와 장비 일부를 잃고 건물 몇 개가 무너지지만 판은 계속된다.

## 6. 시작 깊이

시추기 업그레이드로 열린 깊이 중 원정마다 고른다(1층부터 다시 가서 재료를 모으는 원정도 가능).

## 7. 자원

생체 재료 → 클론(전투·일꾼), 광석 → 건물·방어물·수리, 마정석 → 업그레이드.

## 8. 구현 나눔

- 시뮬레이션(Codex): 전투력 계산, 자동 원정 정책, 빌드 자동화, 건물·방어물 배치 규칙과 체력, 습격 웨이브와 습격자 길 찾기(벽 부수기), 망루 사격, 습격 결과(손실), 시추 깊이, 일꾼 상태.
- 화면(Claude): 건설 패널과 배치 미리보기, 건물 모델, 일꾼 애니메이션, 습격 예고·방어력 표시, 자동 원정·자동 방어 감기 연출, 빌드 방향 선택.

## 9. 엔딩 (2026-10-07 결정)

판은 세 가지로 끝난다.

| 엔딩 | 조건 | 성격 |
|---|---|---|
| 전멸 | 살아 있는 클론이 없고 새 몸을 찍을 생체 재료도 없음 | 실패 |
| 탈출 | 우주선을 완성해 행성을 떠남 | 짧은 판 |
| 정복 | 습격을 모두 막고 15층 마왕을 쓰러뜨림 | 긴 판, 가장 어려움 |

- **탈출:** 우주선은 거점에서 짓는다. 부품에 지하 깊은 층의 재료(마정석, 5·10층 보스 핵)가 들어가서, 짓다 보면 던전을 더 깊이 파게 된다. 발사 전에 최종 습격이 한 번 오고, 이를 버티면 떠난다.
- **정복:** 습격 횟수는 정해져 있다(예: 8회). 모두 막고 15층 마왕을 잡으면 끝난다. 마왕을 먼저 잡아도 남은 습격은 온다.
- 두 엔딩은 같은 판에서 어느 쪽으로든 갈 수 있다.

## 10. 습격 진행 (2026-10-07 결정)

- **참고:** 쓰론폴(밤 시작은 플레이어가, 적이 올 방향 표시, 영웅이 탑·벽과 함께 막음), 돔키퍼(예고와 귀환 긴장).
- **흐름:** 예고(그 전 귀환) → 습격 귀환 시 '습격의 밤' 대기(올 방향·규모 대 방어력 표시, 건설로 보강 가능, 시추공 사용 불가) → 플레이어가 [습격 시작] → 턴제 전투 → 승리 또는 함락.
- **전투 방식:** 턴제(2026-10-07 변경: 실시간 모드를 게임에서 뺐다). 습격자가 맵 끝에서 걸어오는 동안은 시간이 저절로 흐르고, 붙으면 차례마다 명령을 기다린다.
- **자동 방어:** 방어력이 규모의 1.2배 이상이면 [자동 방어]로 결과만 본다.
- **클론 수:** 거점의 클론은 3명보다 많을 수 있다. 지하에 내려가는 주 파티는 3명이고, 남는 클론은 서브 파티로 자동 원정을 돈다. 습격 때 거점에 있는 클론이 방어력에 든다.
