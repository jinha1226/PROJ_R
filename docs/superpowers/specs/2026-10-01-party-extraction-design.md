# 설계 — 파티 익스트랙션 (출격 모드 개편)

작성일: 2026-10-01
상태: 대화 승인. `2026-10-01-extraction-prototype-design.md`(1인 액션 시험판)를 **대체**한다. 외부 피드백(파티 지휘형 익스트랙션 RPG)을 전체 채택했다.
원칙: **기존 코드를 최대한 재사용**한다(WorldSim·전투 AI·길찾기·지역 생성·전리품·가방 규칙·용병 데이터·성장·관계). 기존 주간 게임·탐험·샌드박스·용병단 모드는 동작 변화 없음.

## 0. 핵심
- 플레이어는 공격을 누르지 않는다. **판단한다**: 어디로 갈지, 얼마나 깊이 들어갈지, 무엇을 조사할지, 언제 전투를 끊을지, 언제 철수할지.
- 핵심 감정: "조금만 더 들어가면 더 좋은 걸 얻는다. 하지만 지금 돌아가지 않으면 동료와 전리품을 모두 잃을 수 있다."
- 성공 = 가치 있는 것과 **동료를** 데리고 살아 돌아오기. 적 전멸·맵 완주·보스 처치가 아니다.

## 1. 용병단 (출격 모드 전용 저장)
- 시작 용병 3명(직업 무작위, 기존 `generateRecruit`). **특별한 주인공 없음**.
- 최대 8명, 출격 최대 5명. 거점 **선술집**: 출격마다 후보 2~3명 갱신, 골드로 영입(레벨 비례).
- 성장(레벨업 3택 1·직업 선택)·성격·관계는 기존 시스템 그대로. 출격 중 관계 사건(구출·보호·라이벌·사망 목격)은 기존 관계 갱신 경로로 연결 가능한 형태로 이벤트를 남긴다.
- **게임 오버**: 살아 있는 용병이 0명(거점 대기 포함). 기록 후 새 용병단.

## 2. 파티·리더·짐
- 출격 순서 맨 앞 = 리더. 리더가 쓰러지면 다음 순서의 서 있는 용병이 자동 승계.
- 장비는 **용병별 8부위**(기존 장비 체계를 용병마다).
- 전리품은 **파티 공용 짐**: 칸 = 파티원 가방 칸 합, 무게 한도 = 각자 한도 합. 무거우면 파티 전체 감속. 안전 주머니 파티당 1칸.
- HUD에는 늘 "살아서 가져가면 확보할 가치"를 보이되, 희귀 아이템은 아이콘·이름 알림으로도 의미 있게 보여 준다.

## 3. 손실
- 상태: 정상 → 부상(능력치 감소, 출격 가능) → 중상(출격 불가) → 쓰러짐(출격 중) → 사망. 출격 1회마다 거점에서 한 단계 회복.
- 쓰러짐: 기존 생명줄·구출(동료가 일으켜 세움) 그대로. 생명줄이 다하면 **영구 사망**. 시체에 그 용병의 장비가 남아 **조사로 회수** 가능. 그 용병 몫 가방 칸이 사라져 넘치는 짐은 바닥에 떨어진다.
- 탈출 완료 순간 **탈출 지점 안의 파티원만** 귀환. 쓰러진 채 지점 안 = 귀환 + 중상(2회 출격 불가). 지점 밖 = 실종(이번 단계는 사망 처리).
- 파티 전멸 = 출격 실패(출격 인원 사망, 짐 상실).
- 업기·부축·응급처치·버리고 철수 선택은 **데이터 자리만** 만들고 다음 단계.

## 4. 이동과 추종 (Phase 1)
- 평상시 플레이어는 **리더**를 움직인다. 나머지는 **추종 슬롯**(리더 진행 방향 기준 뒤쪽 V자 분산)으로 따라온다.
- 슬롯이 막혀 있으면(좁은 길·문) 리더의 **발자국 경로**를 따라 한두 줄로 선다. 넓은 곳에서 다시 슬롯으로 복귀.
- 멀어지면 따라잡기 가속(최대 +35%). 25m 넘게 떨어지고 시야 밖이면 리더 뒤 발자국 지점으로 **조용히 재배치**.
- 추종 이동은 기존 `NavGrid` 경로를 재사용하고, 겹침은 기존 분리(separation)·장애물 밀어내기에 맡긴다.
- 카메라: 파티 중심을 추적하되 리더 쪽으로 가중.

## 5. 자동전투와 명령 (Phase 2)
- 발각되거나 접촉하면 파티원 전원이 **기존 전투 AI**(직업·역할·스킬·장비·성격·관계)로 싸운다. 탱커 전방·원거리 후방 같은 진형은 기존 역할 AI가 만든다.
- 전투 판정: 경계 상태의 적이 파티원 10m 안에 있으면 전투 중. 3초간 없으면 전투 종료 → 자동 재집결 → 탐험 상태.
- 전투 중 스틱 입력은 **리더만** 직접 움직인다(나머지는 계속 AI).
- 명령(UI에는 이것만):
  - **집중 공격**: 리더 정면의 가장 가까운 적(또는 탭한 적)을 파티 우선 목표로 지정한다. 기존 AI 점수에 고려 항목 하나를 추가한다.
  - **후퇴**: 파티 전원이 교전을 끊고 리더 뒤쪽(적 반대 방향)으로 3초간 이동한다.
  - **재집결**: 흩어진 파티원을 리더 슬롯으로 2초간 모은다.
- 기본 공격·개별 스킬 버튼은 출격 모드에서 **제거**한다(자동 전투 토글도 불필요).

## 6. UI — 세로·가로 (Phase 3)
- **공통 상태**(`SortieHudState`, 한 곳에서 계산): 파티 상태(HP·부상·쓰러짐), 시간, 위험 단계, 들고 있는 가치, 미니맵 데이터, 조사 대상·진행도, 전투 여부, 명령 가능 여부, 탈출 상태, 짐 상태.
- **레이아웃만 두 벌**: 같은 컴포넌트(파티 바·미니맵·가치·상황 버튼·명령)를 배치만 다르게 한다.
  - 세로(9:16 우선): 상단 = 컴팩트 파티 바(5명 아이콘 + HP + 위험 상태) · 시간·위험 · 가치 · 작은 미니맵. 하단 왼쪽 = 스틱. 하단 오른쪽 = 상황 버튼(조사·후퇴·집중·재집결, 필요할 때만).
  - 가로: 왼쪽 = 파티 상태, 오른쪽 = 미니맵·시간·위험·가치, 하단 = 명령·조사. PC에서는 스틱을 숨긴다.
- 회전해도 **WorldSim을 다시 만들지 않는다**. 레이아웃만 다시 배치한다(`matchMedia('(orientation: portrait)')` + resize).
- 카메라: 세로에서는 조금 더 높은 시점·넓은 세로 시야. 가로는 지금 감각을 유지한다. 게임플레이 차이는 최소화한다.
- 현장 짐 정리 중에도 세계는 진행한다. 모바일에서는 획득·교체·버리기·자동 정리만 두고, 세로에서는 짐 창이 화면 아래 절반을 넘지 않는다.

## 7. 루팅 (Phase 4)
- **자동 획득**: 동전·약초·작은 부산물·흔한 잡동사니·바닥의 일반 아이템. 파티원이 반경 1.2m 안을 지나가면 줍는다. 작은 아이콘 + 짧은 텍스트로 알린다.
- **조사형**: 상자·시체·배낭·제단·잠긴 상자·유물·고급 장비. 조사 버튼을 누르면 리더가 조사한다(일반 1~1.5초, 좋은 상자 2~3초, 특수 구조물은 더 길게). 세계는 계속 진행한다. 이동·피격·전투 시작 시 취소된다.
- 조사 중 나머지 파티원은 바깥을 향해 **경계**하고, 접근하는 적에게 먼저 반응한다.
- 조사가 끝나면 **자동으로 짐에 넣는다**. 다음 경우에만 선택 UI를 띄운다: 짐 칸·무게 부족, 장비 교체 제안, 희귀 아이템.

## 8. 긴장감 (Phase 5)
- **정보 제한**: 시작 시 아는 것은 현재 위치·대략적 지형·탈출 지점·주요 랜드마크 1~2곳뿐이다. POI는 가까이 가거나 시야에 들어오면 발견되고, 발견 후에만 미니맵에 표시된다. 위험도는 숫자나 색 대신 "인기척 있음 / 위험해 보인다" 같은 흐릿한 표시만 준다.
- **소음**: 전투·강한 마법·큰 적 처치·특정 조사·상자 파괴는 소음을 낸다. 주변 적은 `순찰 → 의심 → 조사(소리 난 곳으로) → 전투 → 추적` 단계를 거친다. 바로 정확한 위치로 직선 돌진하지 않는다.
- **배회 적 확대**: POI 사이 이동, 소리 조사, 잠시 머무름, 위험 단계에 따른 경로 변경.
- **위험 증가 + 반랜덤**: 초반(낮은 밀도) → 중반(배회 증가·강한 적 가능) → 후반(정예·탈출로 위험·폐쇄) → 극후반(사냥꾼·정예가 수색). 시점은 ±오차로 흔들리고, 이벤트는 표에서 뽑는다(산적 경보·몬스터 울음·안개·탈출로 집결·마력 이상). 사방에서 몰려오는 무한 웨이브는 금지.
- **위험과 보상 연동**: 후반 고급 상자 활성화, 정예의 희귀 드롭, 숨은 POI, 보스 등장.
- **화면 밖 신호**: 화면 가장자리 위험 방향 표시, 멀리서 나는 전투 소리·울음(소리), 횃불 빛.

## 9. 탈출
- 파티를 탈출 지점(반경 4m)으로 데려가 8초 버틴다. 피격 시 게이지가 줄어든다(초기화가 아니라 감소). 쓰러진 동료가 있으면 진행이 느려진다.
- 일부 지점은 폐쇄되고, 후반 사냥꾼이 쫓아온다.

## 10. 범위 분할 (구현 계획 3개)
1. **Plan 7a** — Phase 1·2·6: 용병단·선술집·용병별 장비·공용 짐, 리더/추종 이동, 파티 자동전투·명령, 쓰러짐·사망·시체 회수·부분 탈출·게임 오버, 파티 봇. 현재 HUD에 파티 상태와 명령을 최소한으로 붙인다.
2. **Plan 7b** — Phase 3·4: 공통 HUD 상태, 세로·가로 레이아웃, 회전 대응, 자동 획득·조사형 루팅·경계·자동 수납·선택 UI.
3. **Plan 7c** — Phase 5: POI 발견·정보 제한, 소음 AI, 배회 확대, 반랜덤 위험·보상 연동, 화면 밖 신호.

## 11. 규칙
- 계층 core → data → sim → app → view/ui, sim에 DOM·three 금지, sim 결정론(`Math.random`·`Date.now` 금지), 파일 300줄.
- Phase마다 `npm test`·`lint`·`typecheck`·`build`(필요시 `e2e`).
- 테스트: 5인 추종·좁은 길·재배치·파티 자동전투·명령·자동 획득·조사 취소·조사 중 적 접근·POI 발견·미니맵 상태·배회·소음 조사·위험 증가·탈출·회전 시 시뮬레이션 유지. 헤드리스 봇을 파티 기반으로 확장한다.
- 밸런스 목표(검증용): 초반 3~4분 탐험 여유, 5~7분 압박 증가, 8~10분 철수 고민, 10분+ 위험하지만 고보상. 항상 오래 버티는 것도, 항상 일찍 나가는 것도 최적이 아니어야 한다.

## 12. Plan 7b 보완 (2026-10-02 대화 승인)
- **세로 = 모바일 최우선**: 상단 띠(컴팩트 파티 바 · 시간·위험 · 가치 · 작은 미니맵), 하단 엄지 영역(왼쪽 스틱, 오른쪽 상황 버튼 3~4개, 최소 56px). 짐 창은 화면 절반 이하의 하단 시트. 세로에서는 시야를 세로로 넓게.
- **줌**: 핀치·휠·+/− 버튼, 기본 배율은 지금보다 가깝게(캐릭터가 작아 보이지 않게), 상·하한, 마지막 배율 기억.
- **속도감**: 출격(지역 모드)에서만 이동속도 약 +30%, 스킬 선딜·후딜·쿨다운 약 −25%, 카메라 추적 민첩하게. 치명타·처치·쓰러짐에 짧은 흔들림, 데미지 숫자 크게. 위험 시계(분)는 유지하고 봇으로 밸런스 재조정. 기존 모드 전투는 불변.
- **루팅**: 자동 획득 반경 약 1.5m. 조사 일반 1초·좋은 상자 2초. 조사 완료 시 자동 수납, 칸·무게 부족·희귀품일 때만 선택 창.
