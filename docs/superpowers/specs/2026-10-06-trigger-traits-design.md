# 발동형 특성 · 궁극기 · 소모품 설계 (초안)

상태: 초안 (2026-10-06). 사용자 결정: 직업 액티브 기술을 없애고 **발동형**으로 바꾼다. 액티브는 **직업마다 궁극기 하나 + 소모품**만. 참고: Path of Achra(발동형 능력의 연쇄), DCSS·SPD(조합과 아이템의 다양함), 쥬피터 헬(단순한 조작).

## 1. 원칙

- 한 턴에 하는 일: **이동 · 공격 · 소모품 사용 · 궁극기 · 대기.** 그 밖의 모든 능력은 조건이 맞으면 알아서 터진다.
- 같은 **발동 엔진** 위에 세 겹이 쌓인다. 셋이 서로 연쇄되는 것이 빌드의 재미다.
  1. **직업 기본 발동:** 영혼이 깃들 때 처음부터 갖는다.
  2. **레벨업 특성:** 레벨마다 카드 3장 중 1장을 고른다(최대 15레벨).
  3. **장비 효과:** 줍는 장비(무기·갑옷·장신구)의 발동 효과. 파티 연계는 특성과 장비의 #협공 효과 조합으로 생긴다.
- 동료 AI는 기술 타이밍을 고민할 필요가 없다. 이동, 대상 선택, 궁극기, 물약만 판단한다.

## 2. 발동 엔진

**조건(언제)**

| 조건 | 뜻 |
|---|---|
| 적중 | 내 공격이 맞았을 때 |
| 치명 | 치명타가 터졌을 때 |
| 처치 | 내가 적을 쓰러뜨렸을 때 |
| 피격 | 내가 맞았을 때 |
| 막기·회피 | 공격을 막거나 피했을 때 |
| 위기 | 내 체력이 절반 아래로 처음 떨어질 때(전투마다 1회) |
| N번째 | 공격 N번마다 |
| 제자리 | 이동하지 않고 공격했을 때 |
| 이동 | 한 칸 움직였을 때 |
| 아군 적중 | 2칸 안의 동료가 적을 맞혔을 때 |
| 아군 위기 | 동료의 체력이 50% 아래로 떨어질 때 |
| 전투 시작 | 무리가 알아챘을 때 |
| 상태 부여 | 내가 적에게 상태 이상을 걸었을 때 |
| 궁극기 | 궁극기를 썼을 때 |

**효과(무엇을)**
- 추가 피해, 범위 피해, 상태 이상 부여, 치유, 보호막, 강화, 추가 공격, 순간이동, 소환, 확산(상태를 주변으로), 폭발(상태를 터뜨림), 궁극기 충전 감소.

**규칙**
- 발동마다 내부 대기시간이 있을 수 있다(예: 6초).
- 한 번의 행동에서 연쇄는 최대 5번까지 처리한다(무한 루프 방지).
- 화면에는 발동마다 특성 이름이 짧게 뜬다(예전 던전 게임의 각인 팝업처럼).

## 3. 상태 이상과 반응

| 상태 | 효과 |
|---|---|
| 화상 | 초당 3 피해, 3초 |
| 빙결 | 행동 불가, 2초. 무거운 일격에 **파쇄**(피해 2배) |
| 냉기 | 행동 50% 느려짐, 3초 |
| 중독 | 초당 2 × 중첩(최대 5), 4초 |
| 감전 | 다음에 맞으면 2칸 안의 적에게 전류가 튐 |
| 출혈 | 움직일 때마다 4 피해, 4초 |
| 기절 | 다음 행동 1초 지연 |
| 표식 | 모든 아군에게 받는 피해 +30%, 4초 |
| 노출 | 받는 피해 +50%, 3초 |

**반응**
- 화상 + 중독 → **독연 폭발**: 주변 적 모두 중독 2중첩.
- 빙결 + 무거운 일격 → **파쇄**: 피해 2배.
- 감전 + 출혈 → **혈전**: 출혈 피해 2배.

## 4. 태그

모든 특성과 각인에 태그를 하나 이상 붙인다. 이미 가진 태그의 카드가 더 자주 나온다(빌드가 한 방향으로 모인다).

`#근접` `#원거리` `#화염` `#냉기` `#독` `#전기` `#출혈` `#방패` `#은신` `#치유` `#협공` `#소환` `#생존` `#치명`

## 5. 직업: 기본 발동과 궁극기

궁극기는 직업마다 하나, 대기시간 30~45초. 턴제에서는 그 클론의 차례에 쓰고, 실시간에서는 예약된다. 동료 AI도 조건이 맞으면 쓴다(예: 적 셋 이상, 아군 위기).

| 직업 | 기본 발동 | 궁극기 |
|---|---|---|
| **전사** | **포위 베기:** 붙은 적 2명 이상이면 회전베기 (6초) · **응수:** 근접 공격을 막으면 반격 | **전장의 함성:** 4칸 안 적 모두 5초 도발, 아군 전원 보호막 15 (35초) |
| **궁수** | **기습 사격:** 상처 없는 적에게 첫 사격은 치명 · **정조준:** 제자리 연속 사격마다 피해 +10% (최대 30%) | **화살비:** 지정한 3×3 범위에 화살 5발 (35초) |
| **마법사** | **연쇄 주문:** 세 번째 공격마다 화염구 · **파쇄:** 언 적을 치면 피해 2배 | **운석:** 지정한 5×5 범위 큰 화염 피해 + 화상 (45초) |
| **성직자** | **구원의 손:** 아군 체력이 50% 아래로 떨어지면 치유 22 (8초) · **축복:** 전투 시작 시 파티 보호막 10 | **신성 결계:** 3칸 안 아군 3초간 피해 무효 (45초) |
| **도적** | **배후 급소:** 다른 아군을 노리는 적을 치면 피해 1.6배 · **잠행:** 처치하면 1초 은신 | **그림자 난무:** 4칸 안 적 최대 4명에게 순간이동 연속 베기 (35초) |

**상위 직업:** 레벨 8부터, **빌드 구성만으로** 정해지는 조건을 채우면 전직한다(아크라식). 플레이 기록(몇 번 처치 등)은 조건에 넣지 않는다. 태그는 특성과 장비 모두에서 센다. 전직하면 기본 발동 하나가 더 붙고, 궁극기가 강화형으로 바뀐다.

| 기본 → 상위 | 조건 |
|---|---|
| 전사 → 광전사 | #근접 4 + #출혈 2 |
| 전사 → 수호기사 | #방패 4 + 방패 착용 |
| 궁수 → 저격수 | #치명 4 + 석궁 착용 |
| 궁수 → 사냥꾼 | #출혈 2 + #독 2 |
| 마법사 → 원소술사 | 원소 태그 3종(#화염·#냉기·#전기) 각 1 이상 |
| 마법사 → 강령술사 | #소환 3 |
| 성직자 → 심판관 | #방패 2 + #근접 2 + 둔기 착용 |
| 성직자 → 치유사 | #치유 4 |
| 도적 → 암살자 | #은신 2 + #치명 3 |
| 도적 → 독술사 | #독 4 |

- **조건은 처음부터 공개한다.** 아크라처럼 목표 상위 직업을 정하고 키울 수 있다.
- **범용 상위 직업 "베테랑":** 레벨 10까지 어떤 조건도 못 채웠다면 누구나 고를 수 있다. 모든 피해 +10%, 최대 체력 +15%, 궁극기 대기 -20%.

**빌드 방향 표시:** 핍보이 상태창에 내가 가진 태그 분포와 두 상위 직업(및 베테랑)의 조건 충족 상황을 보여 준다. 레벨 8 전에도 방향이 보인다. (나중에) 특이한 태그 조합으로 열리는 숨은 직업(예: 전사 + #화염 3 → 화염 검사)을 둘 수 있다.

| 상위 직업 | 추가 발동 | 궁극기 변화 |
|---|---|---|
| 광전사 | 체력 절반 아래면 공격 속도 2배 | 함성 → **피의 광란:** 5초간 흡혈 30% |
| 수호기사 | 곁의 아군이 받는 피해 30%를 대신 받음 | 함성 → 보호막 30 |
| 저격수 | 5칸 밖 적에게 피해 2배 | 화살비 → **관통탄:** 일직선 끝까지 관통 |
| 사냥꾼 | 사격이 25% 확률로 적을 묶음 | 화살비에 출혈 |
| 원소술사 | 화염구가 냉기·감전 중 하나를 무작위로 추가 | 운석 → 원소 폭풍(세 원소 모두) |
| 강령술사 | 처치한 적이 10초 해골로 일어남 (최대 2) | 운석 → **망자의 군세:** 시체마다 해골 |
| 심판관 | 적중마다 가장 다친 아군 치유 2 | 결계 → **심판의 빛:** 범위 적 기절 + 피해 |
| 치유사 | 넘친 치유는 보호막 | 결계 시간 5초 |
| 암살자 | 체력 35% 미만 적에게 2배 | 난무 대상 6명 |
| 독술사 | 모든 공격에 중독 1중첩 | 난무 → **독안개:** 범위 중독 5중첩 |

### 6.3 상위 직업 특성 (상위 직업마다 2 × 10 = 20)

전직한 뒤에만 나온다. 예시: 광전사 **피의 굶주림**(처치 → 체력 10% 회복), 수호기사 **불굴의 방패**(막기 → 2칸 안 아군 보호막 5), 저격수 **숨 고르기**(3턴 제자리 → 다음 사격 3배), 사냥꾼 **덫**(묶인 적에게 출혈), 원소술사 **원소 공명**(서로 다른 원소 2개가 걸린 적 → 폭발), 강령술사 **뼈의 갑옷**(해골이 있는 동안 받는 피해 -20%), 심판관 **신벌**(기절한 적에게 피해 2배), 치유사 **생명의 샘**(보호막이 깨지면 치유 10), 암살자 **처형**(25% 미만 적 즉사 확률 20%), 독술사 **독의 정수**(중독 최대 중첩 +3). 나머지 10개는 같은 방식으로 채운다.

### 6.4 결정적 특성 (6, 레벨 10·14에 4번째 카드로 등장)

강력하지만 대가가 있다. 한 영웅이 하나만 가질 수 있다.

| 특성 | 효과 | 대가 |
|---|---|---|
| 피의 계약 | 궁극기가 대기 대신 체력 30%를 쓴다 | 회복 효과 -30% |
| 그림자 서약 | 은신 중 매초 체력 5% 회복, 은신 공격 3배 | 은신 아닐 때 받는 피해 +25% |
| 불사 | 죽을 피해를 받으면 3초 무적 (전투당 1회) | 최대 체력 -25% |
| 광신 | 모든 발동의 대기시간 절반 | 이동 -20% |
| 원소의 화신 | 모든 공격에 무작위 원소 | 치명 불가 |
| 고독한 늑대 | 2칸 안에 아군이 없으면 피해 +60% | 결속·협공 효과 무효 |

### 6.5 제시 규칙

- 카드 3장: 직업(또는 상위 직업) 풀 2장, 공통 1장.
- 이미 가진 태그의 카드는 뽑힐 확률 2배.
- 레벨 10과 14에는 결정적 특성 1장이 4번째 카드로 추가된다.
- 3단계를 다 채운 특성은 다시 나오지 않는다.

## 7. 장비 (아크라식, 2026-10-06 결정)

장비도 특성과 **같은 발동 엔진과 태그**를 쓴다. 그래서 장비와 특성이 서로 연쇄되며 빌드가 완성된다.

### 7.1 칸 (영웅당 3칸, 파티 9칸)

| 칸 | 내용 |
|---|---|
| 무기 | 양손 무기 하나, 또는 한손 무기 + 방패(같은 칸에서 해결) |
| 갑옷 | 방어구 하나. 무게가 있음 |
| 장신구 | 반지·목걸이 같은 발동 장비 하나 |

- 칸을 줄인 이유: 영웅 셋을 관리하므로 칸이 많으면 비교·교체 피로가 크다(특히 모바일).
- **전용 연계 칸은 두지 않는다.** 파티 연계는 특성(결속, 사기, 아군 적중 발동)과 장비의 #협공 효과 조합으로 생긴다. 예전의 연계 각인(미끼, 공명 파쇄, 사냥 표식, 수호 서약, 메아리)은 일반 장신구의 효과로 들어간다.

### 7.2 장비 하나의 구성

- **이름 있는 고정 장비**가 기본이다. 무작위 옵션은 쓰지 않는다. 처음에는 **36종 안팎**(무기 18, 갑옷 8, 장신구 10)으로 시작해 반응을 보며 늘린다.
- 수치: 피해·사거리·공격 속도(무기), 방어·막기·저항(갑옷), **무게**.
- **발동 효과 1~2개**와 **태그**. 레벨업 특성과 같은 문법(적중, 처치, 막기, 제자리, 상태 부여…)이다.
- **등장 층 범위:** 깊을수록 강하고 기묘한 효과의 장비가 나온다.
- **양손·방패 보너스:** 양손 무기나 한손 + 방패 조합에만 붙는 효과가 있다.
- **무게:** 클수록 이동과 공격이 느려진다.

### 7.3 무기 숙련 (직업 차이)

누구나 아무 무기나 낄 수 있지만, 직업의 **숙련 무기**일 때만 제 성능이 나오고 **직업 기본 발동이 켜진다.** 숙련 밖이면 피해 -30%, 공격 시간 +20%, 직업 기본 발동이 꺼진다. 무기 계열은 8종이다.

| 계열 | 기본 공격 | 숙련 직업 |
|---|---|---|
| 한손검 (+방패 가능) | 무난한 근접 | 전사 |
| 양손 무기 (대검·도끼) | 느리지만 주변까지 베기 | 전사 |
| 둔기 (+방패 가능) | 기절 확률 | 성직자, 전사 |
| 단검 | 아주 빠름, 치명 확률 | 도적 |
| 활 | 먼 사거리 | 궁수 |
| 석궁 | 강하지만 느림 | 궁수 |
| 지팡이 | 원소 공격, 대상 주변에 튐 | 마법사 |
| 성물 | 짧은 원거리 신성 | 성직자 |

- 창, 투척, 완드 같은 개성(2칸 찌르기, 짧은 원거리 등)은 고유 장비의 효과로 표현한다.
- 상위 직업은 숙련 범위가 바뀐다. 예: 광전사는 양손 무기 보너스, 수호기사는 방패 막기 강화, 사냥꾼은 단검 숙련 추가.
- 갑옷과 장신구는 직업 제한이 없다. 차이는 무게로만 둔다.

### 7.4 희생

안 쓰는 장비를 바치면, 같은 칸에 낀 장비가 바친 장비 수치의 **25%**만큼 영구히 강해진다(아크라식). 가방이 차는 문제도 이걸로 푼다.

### 7.5 잃을 때

이미 정한 대로: 쓰러진 클론의 장비는 그 자리에 떨어지고, 같은 원정 안에서 주우면 회수, 층을 떠나면 사라진다.

### 7.6 예시 장비

| 장비 | 칸 · 태그 | 효과 |
|---|---|---|
| 피 묻은 대검 | 양손 · #출혈 | 적중 시 출혈. 출혈 중인 적을 처치하면 다음 공격 2배 |
| 얼음 박힌 장궁 | 활 · #냉기 | 제자리 사격 세 번째마다 빙결 |
| 독사의 이빨 | 단검 · #독 | 적중 시 중독 1중첩. 쌍수면 2중첩 |
| 잿불 지팡이 | 지팡이 · #화염 | 화염구가 화상 지대를 3초 남김 |
| 순례자의 성물 | 성물 · #치유 | 치유하면 대상 주변 적에게 신성 피해 5 |
| 방벽 방패와 검 | 한손검+방패 · #방패 | 막으면 2칸 안 아군 보호막 5 |
| 망자의 목걸이 | 장신구 · #소환 | 처치하면 20% 확률로 해골 소환 (10초) |
| 사냥꾼의 망토 | 갑옷 · #은신 | 전투 시작 시 1초 은신 |
| 광전사의 팔찌 | 장신구 · #근접 | 피격 시 다음 공격 속도 2배 |
| 순풍의 반지 | 장신구 · #생존 | 이동 후 첫 피격 회피 |
| 천둥의 반지 | 장신구 · #전기 | 치명이 터지면 주변 2칸 감전 |
| 미끼 부적 | 장신구 · #협공 | 내가 도발한 적은 5초간 노출(모든 아군 피해 +50%) |
| 사냥 표식 반지 | 장신구 · #협공 | 내 공격이 대상에 표식 → 다른 아군 피해 +30% |
| 철갑 흉갑 | 갑옷 · #방패 | 방어 높음, 무게 큼. 제자리 2턴이면 받는 피해 -20% |

## 8. 소모품

공용 가방에 들어가고, 쓰는 데 한 턴(실시간에서는 짧은 행동)이 든다. 던전 상자와 적에게서 나온다.

| 소모품 | 효과 |
|---|---|
| 치유 물약 | 체력 40% 회복 |
| 화염 폭탄 | 3×3 범위 피해 + 화상 |
| 빙결 폭탄 | 3×3 범위 빙결 |
| 독 단지 | 3×3 범위 중독 3중첩 |
| 연막탄 | 3×3 범위의 아군 2초 은신, 적 명중 -50% |
| 정화 두루마리 | 파티 전원 상태 이상 해제 |
| 분노의 물약 | 5초간 피해 +40% |
| 번개 완드 | 충전 3회. 일직선 감전 피해 |

## 9. 기존 코드에서 바뀌는 것

- 직업마다 기술 2개(Q·W) → **궁극기 1개(키 R, 버튼 하나)**. 동료 자동 기술은 궁극기 판단만 남긴다.
- 지금의 레벨업 특성 18개(수치형)는 공통 특성과 직업 특성으로 흡수·대체한다.
- 예전 던전 게임의 **각인 엔진(조건 → 효과)**과 원소 반응을 발동 엔진의 바탕으로 쓴다.
- 지금 Codex가 만드는 장비(무작위 등급·옵션, 무기 1·방어구 1·장신구 2칸)는 **뼈대(가방, 착용·교체, 상자·드랍, 죽으면 떨어짐, 깊이별 보상)를 유지**하고, 데이터는 7장의 아크라식(고정 장비 + 발동 효과 + 영웅당 3칸 + 숙련 + 희생)으로 바꾼다. 연계 각인은 일반 장신구 효과로 들어간다.
- 화면: 파티 프레임의 기술 칸 2개 → 궁극기 칸 1개 + 발동 팝업. 핍보이 상태창에 기본 발동과 특성 목록.
