# 설계 — 판타지 익스트랙션 시험판 (주인공 단독 출격)

작성일: 2026-10-01
상태: 대화 승인(섹션별). 기존 게임(주간 진행 `2026-10-01-weekly-exploration-design.md`)은 **그대로 두고**, 타이틀에서 들어가는 **독립 모드**로 만든다.
재미가 확인되면 본 게임에 합친다(별도 설계).

## 0. 목적과 범위

**검증할 질문**: "더 들어가면 더 좋은 걸 얻지만, 지금 죽으면 다 잃는다" — 혼자 들어가서 줍고, 고민하고, 살아 나오는 루프가 재미있는가.

**성공 조건(출격 단위)**: 적을 다 잡거나 맵을 다 도는 게 아니라 **가치 있는 것을 들고 살아 돌아오는 것**.

**이번에 하는 것**: 거점(창고·장착·상인) · 넓은 지역 한 장 · 관심 지점 · 지역 전체 단일 시뮬레이션 · 주인공 직접 조작(키보드/패드/터치) · 루팅 · 칸+무게 인벤토리 · 위험 시계 · 탈출 · 사망 손실.

**이번에 하지 않는 것**: 동료 출격, NPC 모험가(Plan 7), 여러 지역·지역 해금·명성 등급, 제작·시설·스킬북·퀘스트(Plan 8), 출격 중 저장·이어하기, 기존 주간 게임과의 통합.

장기 방향(참고, 이번 범위 아님): 열린 캠페인(12주 마감 없음), 지역 보스 처치로 다음 지역 해금, 명성 등급, 탐험대 전멸 시 탐험대 전원의 장착 장비 상실, 후반 자동 파견.

## 1. 루프와 거점

타이틀 `출격 (시험)` → **거점** → 출격 → 탈출 또는 쓰러짐 → **결과** → 거점.

- **창고**: 40칸. 탈출로 가져온 물건이 들어가는 안전 자산. 창고가 넘치면 정리 전까지 출격 불가.
- **장착**: 8부위(2장) + 퀵슬롯(벨트가 정함) + **안전 주머니 1칸**.
- **상인**: 아이템을 가치 그대로 사 주고, 가치의 2배에 판다. 포션·기본 장비 상시 판매. 골드는 거점에만 있고 출격에 들고 가지 않는다.
- **무료 기본 장비**: 낡은 무기와 누더기를 언제든 받을 수 있다(전부 잃어도 다시 출격 가능, 진행 막힘 없음).
- **성장**: 처치·탈출 경험치 → 레벨업 3택 1, 레벨 3 직업 선택(기존 시스템 재사용).

## 2. 장비 8부위

| 칸 | 주 역할 | 의미 |
|---|---|---|
| 무기 | 공격력·공격 방식(직업별) | 화력 |
| 머리 | 체력·방어 | 큰 한 방 대비 |
| 가슴 | 방어(가장 큼), 무거움 | 튼튼함 vs 무게 |
| 장갑 | 공격 속도·치명 | 빨리 끝내기 |
| 신발 | 이동 속도·회피 | 도주·탈출 |
| 벨트 | 퀵슬롯 수 1~4 | 위기 대응력 |
| 장신구 | 특수 효과(흡혈·선제 등 기존 고유 효과) | 개성 |
| 가방 | 가방 칸 수·무게 한도 | 회수량 |

- 장착 장비 무게도 총무게에 포함된다(무겁게 무장 vs 가볍게 많이 회수).
- 외형: 무기 모델·투구·망토·갑옷 색은 확실히 반영. 장갑·신발·벨트는 해당 부위 색으로 등급 표시(가능 범위는 구현 계획에서 모델 구조 확인 후 확정).

## 3. 아이템

| 분류 | 예 | 용도 |
|---|---|---|
| 장비 | 8부위 | 장착 |
| 소모품 | 체력 포션, 해독제, 연막탄(발각 해제), 귀환 두루마리(10초 시전 후 즉시 탈출, 희귀) | 위기 관리 |
| 몬스터 부산물 | 늑대 가죽, 해골 가루, 거미 독샘 | 판매 |
| 잡동사니 | 녹슨 촛대, 은수저 | 판매(가볍고 쌈) |
| 희귀 유물 | 고대 왕관, 봉인된 성배 | 고가, 무거움 |
| 열쇠 | 보물방 열쇠 | 잠긴 보물방 개방 |

- **등급**: 일반 / 고급 / 희귀 / 영웅 / 전설(기존 장비 등급 0~4 재사용). **아이템 칸의 테두리 색**으로 표시 — 회색 / 초록 / 파랑 / 보라 / 주황. **종류는 칸 안 아이콘**으로 구분.
- 모든 아이템은 가치(골드)와 무게를 가진다.

## 4. 인벤토리(칸 + 무게)

- 가방 칸 수: 맨몸 주머니 6 → 소형 10 → 중형 14 → 대형 18. 포션·부산물·잡동사니는 한 칸에 3~5개 겹침.
- 무게: 한도의 60%까지 영향 없음, 60~100%에서 이동 속도 최대 −30%(선형), 한도 초과 시 줍기 불가.
- **HUD에 "들고 있는 가치 합계"를 상시 크게 표시**("지금 죽으면 이만큼 잃는다").
- 루팅: 상자·시체·배낭 상호작용 → **뒤지는 1~2초 동안 무방비** → "상자 ↔ 가방" 두 칸 목록(꺼내기·버리기·바로 장착). 버린 물건은 그 자리에 남는다. 현장 장비 교체 2초.
- 키보드·패드·터치가 같은 UI를 쓴다. 칸 최소 48px.

## 5. 결과와 손실

- **탈출 성공**: 가방 + 장착 장비 전부 → 거점(창고·장착 유지).
- **쓰러짐**: 가방과 장착 장비 전부 상실. **안전 주머니 1칸만 유지**. 주인공은 잃은 채 거점으로 복귀(게임 오버 없음).
- **출격 중 새로고침/이탈(시험판)**: 출격은 저장하지 않는다. 출격 전 상태로 거점에 돌아온다(얻은 것·잃은 것 없음). 손실 회피가 가능한 **알려진 한계**이며 저장 방식은 다음 단계에서 정한다.
- 결과 화면: 탈출이면 가져온 목록·가치·경험치, 쓰러짐이면 잃은 목록.

## 6. 지역

- 약 **120 × 90m** 연속 맵 한 장. 숲·폐허·묘지 에셋(기존 KayKit env) 혼합. 큰 지형 틀(길·강·절벽)은 몇 가지 틀 중 선택, 관심 지점 위치·내용·적·전리품은 출격마다 섞인다.
- 시야: 주인공 주변 약 18m. 가 본 곳은 미니맵에 남음. 관심 지점의 이름·위치는 처음부터 지도에 보이고 내용은 모른다.
- 관심 지점 출격마다 **8~10곳**(한 판에 3~4곳 방문 밀도).

| 지점 | 위험 | 대표 보상 |
|---|---|---|
| 폐허 | 낮음, 산적 소수 | 잡동사니, 기본 장비 |
| 산적 캠프 | 중간, 무리 | 보급 상자(포션), 골드 주머니 |
| 몬스터 둥지 | 중간~높음, 다수 | 몬스터 부산물 |
| 고대 신전 | 높음, 정예 수호자 | 희귀 장비, 유물 |
| 잠긴 보물방 | 열쇠 필요 | 고가 유물 |
| 독안개 늪 | 지속 피해 | 비싼 약초·유물 |
| 보스 구역 | 최상, 보스 | 최상급 장비 |

맵 곳곳에 상자·쓰러진 모험가의 배낭·약초 같은 작은 루팅거리.

**적**: 관심 지점 수비대 + 길을 도는 순찰조. 시야(전방 부채꼴 + 근접 감지)로 발각, 무리에 전파. 뒤에서는 덜 들킨다(잠입 통과 가능). 자기 자리에서 너무 멀어지면 복귀(추격 한계 → 도주가 통함). 위험 시계 후반의 사냥꾼만 끝까지 추적.

## 7. 위험 시계와 탈출 (한 판 약 10분, 모바일 고려)

| 시간 | 단계 | 변화 |
|---|---|---|
| 0~4분 | 낮 | 기본 |
| 4~7분 | 해질녘 | 순찰조 증가 |
| 6분 30초 | 경고 | "탈출 지점 하나가 곧 닫힌다" |
| 8분 | 밤 | 탈출 지점 하나 닫힘, 시야 축소, 강한 몬스터 등장 |
| 10분~ | 마력 폭풍 | 사냥꾼 정예 추적, 시간이 갈수록 강해짐 |

- 강제 사망 시간제한은 없다. 오래 있을수록 살아 나가기가 어려워질 뿐.
- 후반 일부 상자는 품질이 오른다(버틴 자의 몫).
- **탈출**: 시작 시 탈출 지점 2~3곳 표시(하나는 밤에 닫힘). 지점 안에서 **8초 버티면** 탈출, 피격 시 처음부터. 탈출 지점 근처는 적이 몰리기 쉽게 배치.

## 8. 시뮬레이션 구조 (지역 전체 단일 시뮬레이션)

새 `src/sim/world/`가 기존 전투 엔진을 감싸 지역 전체를 **하나의 결정론적 시뮬레이션**(초당 20틱)으로 돌린다. 기존 방 전투·샌드박스·주간 게임은 지금 동작 그대로(아래 확장은 모두 기본값이 현재 동작).

**전투 엔진 확장**
- 경계: 고정 `ARENA` 대신 설정에서 받는다(기본 = 현재 24×14).
- 잠든 유닛: 활성 반경(약 25m) 밖·비경계 유닛은 AI·이동·타깃 후보에서 제외. 공간 격자로 주변 탐색.
- 직사각형 장애물(벽·건물): 이동·시야·투사체가 존중.
- 길찾기: 1m 격자 A*. 직선 통행 가능하면 기존처럼 직진.
- 종료 조건: 지역 모드에서는 팀 전멸 판정을 끄고 지역 규칙(탈출·쓰러짐)이 출격을 끝낸다.
- 주인공 쓰러짐(단독) = 출격 실패.

**지역 층(world)**: 위험 시계, 순찰 경로·수비 위치, 발각·전파·추격 한계, 야간/폭풍 스폰, 탈출 게이지, 루팅·상호작용, 독안개 피해, 활성화 관리.

**주인공 직접 조작**: 주인공 AI 판단을 끄고 매 틱 입력 명령(이동 벡터·공격·스킬·아이템·상호작용)을 시뮬레이션 명령으로 넣는다(기록 가능, 결정론 유지). 자동 전투 전환 가능(접근성 + 밸런스 봇 경로).

| 동작 | 패드 | 키보드 | 터치 |
|---|---|---|---|
| 이동 | 왼쪽 스틱 | WASD | 왼쪽 가상 스틱(엄지 위치에 생성) |
| 기본 공격(바라보는 방향 가까운 적 자동 조준) | A | J/클릭 | 오른쪽 큰 버튼 |
| 액티브 1·2 | X·Y | K·L | 공격 버튼 둘레 |
| 궁극기 | RB | ; | 공격 버튼 둘레 |
| 퀵슬롯 | 십자키 | 1~4 | 위쪽 슬롯 |
| 상호작용 | B | E | 대상 근처에서 떠오르는 버튼 |
| 자동 전투 전환 | Select | Tab | 메뉴 |
| 일시정지(가방 정리 가능) | Start | Esc | 메뉴 |

범위 스킬은 바라보는 방향 앞쪽에 떨어진다. 스킬은 기존 직업 스킬 그대로.

**렌더링**: 지형은 지역 단위 인스턴싱, 캐릭터 모델은 화면 근처 유닛만 생성·회수 재사용, 카메라는 기존 쿼터뷰 추적(Z/X 회전). 가로 화면 기준.

**성능 예산**: 데스크톱 60fps, 모바일 30fps 이상. 전체 유닛 ≤ 120, 동시 활성 ≤ 20. 모바일은 그림자 끔·해상도 배율 낮춤.

**계층 규칙 유지**: core → data → sim → app → view/ui, sim은 three/DOM 금지, sim에서 `Math.random`/`Date.now` 금지, 파일 300줄 제한.

## 9. 저장

- 별도 키 `projr.extract.v1`: 창고, 장착, 안전 주머니, 골드, 주인공 성장. 기존 `projr.run.v2`와 섞이지 않음.
- 거점에서만 저장(출격 시작 직전·결과 반영 직후). 출격 중 상태는 저장하지 않는다(5장 참고).

## 10. 테스트와 밸런스

- **시뮬레이션 단위 테스트**: 잠든/활성 유닛 전환, 직사각형 장애물 충돌·시야, 길찾기, 발각·전파·추격 한계, 위험 시계 단계·탈출 지점 닫힘, 탈출 게이지(피격 시 초기화), 전리품 표, 칸·무게·겹침 규칙, 사망 손실과 안전 주머니, 입력 명령 재생 결정론, 기존 전투(경계 기본값) 무변화.
- **봇 출격(헤드리스, 주인공 AI)**: 탈출률·평균 회수 가치·평균 출격 시간 측정. 목표: **6분 안에 나오는 봇 탈출률 60~70%, 10분 넘게 버티는 봇 30% 미만**, 회수 가치는 시간에 따라 증가.
- **e2e**: 출격 → 이동 → 상자 루팅 → 탈출 → 창고 확인 / 쓰러짐 → 장비 상실 / 출격 중 새로고침 → 출격 전 상태 복귀.

## 11. 시험판 성공 기준 (재미 검증)

- 한 판 약 10분, 판마다 "버릴까 챙길까" 고민 3번 이상.
- 죽으면 확실히 아프지만 무료 기본 장비로 1~2판 안에 회복 가능.
- 데스크톱 60fps / 모바일 30fps 이상.
