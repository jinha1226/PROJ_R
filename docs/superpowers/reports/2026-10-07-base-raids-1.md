## Public API for the UI

All simulation APIs are under `src/sim/base/` unless specified otherwise. `p` is `WorldParty`; `ev` is an optional caller-owned `GEvent[]`.

| Module | Signature | Behavior |
| --- | --- | --- |

| drill | `drillCost(level: number): { ore: number; crystal: number } \| undefined` | Cost to reach a supported level, 1–3. |
| drill | `canUpgradeDrill(p): boolean`, `upgradeDrill(p, ev?: GEvent[]): boolean` | Atomic spend; first upgrade arms raid clock. |
| drill | `startFloors(p): number[]` | Unlocked choices: 1, 3, 5, 8. |
| drill | `startDelve(p, seed: number, carry: Carry, floor = 1): DelveParty \| null` | Construct a delve at an unlocked floor; no trip lifecycle changes. |
| buildings | `BUILDINGS`, `BuildingKind`, `Building` | Definitions, footprint sizes, costs, HP; instance IDs and terrain snapshots. |
| buildings | `canPlace(p, kind: BuildingKind, at: Cell): boolean`, `place(p, kind, at): boolean` | Whole-footprint validation and atomic placement/spend. |
| buildings | `buildingsAt(p, at: Cell): Building \| undefined` | Finds an instance anywhere in its footprint. |
| buildings | `demolish(p, id: string): boolean`, `removeBuilding(p, id: string): boolean` | Restore terrain; demolition refunds half, destruction refunds nothing. |
| buildings | `recommendedLayout(p): { kind: BuildingKind; at: Cell }[]` | Affordable preview; call `place` for each entry. |
| buildings | `onReturn(p): void` | Infirmary healing only; lifecycle callers should use `returnToSurface`. |
| gear | `sacrificeRate(p: RoamParty): number` | 0.35 with a surface forge, otherwise 0.25; `sacrifice` uses it. |
| raids | `raidSize(p): number`, `defencePower(p): number` | Wave threat and eligible base defence. |
| raids | `onRaidReturn(p, deepest = p.deepest): GEvent[]` | Count return, update depth, heal, warn/spawn; normally called by trip helper. |
| raids | `startRaid(p): GEvent[]` | Explicit wave spawn; refuses while away or already under attack. |
| raids | `autoDefend(p, ev?: GEvent[]): { won: boolean; losses: RaidLosses } \| null` | Resolve victory at defence ≥ active wave size × 1.2; otherwise leave live raid alone. |
| trips | `departSurface(p, seed: number, carry: Carry, floor = 1): DelveParty \| null` | Expedition entry; freezes surface, rejects active raids, repeated departure, empty parties and locked depths. |

| worldSim | `worldTick(p, dt: number): GEvent[]`, `canDrill(p): boolean` | Existing APIs now include raid ticking and departure restrictions. |

`Expedition.down(c, floor = 1)` accepts selected depth through the backward-compatible `WorldDemo` option `onDrill?: (c: Carry, floor?: number) => void`. Expedition uses `departSurface` / `returnToSurface`. Do not separately invoke `onRaidReturn` for the same return. `returnToSurface` returns events and also queues them for the existing `worldTick` consumer; use one presentation path to avoid showing them twice.

### State and events

`WorldParty` adds `drillLevel`, `buildings`, `nextBuilding`, `trips`, `raidClock`, `raidsDone`, `deepest`, `podHp`, `raid`, `away`, and `baseEvents`. Initial pod HP is 200; raid is null; raidClock is null until armed. Buildings, claimed land, drill level, counters and pod HP survive `takeParty` / `placeParty`. `Carry.deepest` is optional for compatibility; new delves and subsequent descents track the maximum visited floor.

- Upgrade: `{ type: 'buff', text: 'drill' }` into the supplied event list.
- Warning: `{ type: 'buff', text: 'raidSoon', amount: raidSize(p) }`.
- Spawn: `summon` with `dst` raider ID and `to` edge cell.
- Combat: existing `move`, `bump`, `shoot`, `hit`, `die` events. Tower `src` is its building ID; building `dst` is its ID; pod `dst` is `'pod'`.
- Victory: `{ type: 'buff', text: 'raidWon' }`.
- Loss: `{ type: 'dead', text: 'raidLost' }`; this is a recoverable raid outcome.

Event text tokens are identifiers, following the plan's GEvent examples; UI translations should use terse Korean labels. The loss object is `{ ore: number, crystal: number, buildings: string[] }` and automatic victories have zero losses.

## Rulings

- Arming return counts as return zero: without upgrades, trip 4 arms, trip 5 warns, trip 6 raids. After an upgrade, first return warns and second raids. Every second return thereafter triggers the next wave.
- Threat is `10 × (3 + 2 × raidsDone + floor((deepest - 1) / 3))`; goblins/archers contribute 10 and brutes 20. Completed losses also advance `raidsDone`.
- Defence counts living nonsummoned clones within six cells of the pod, plus 15 per tower and 1 per wall. Automatic victory consumes no materials and grants no free corpse loot.
- The generator's solid border requires connected entrances. A seeded choice opens entry cells on one or two sides and connects them to existing reachable land. It creates no camps or stray spawns.
- Raid routes use reverse Dijkstra: ordinary steps cost 1; breakable buildings cost 8. Raiders break walls/gates and other solid facilities, respecting corners; palisades remain walkable cover. Raiders stay awake outside normal roam leash range.
- Gates are floor tiles for hero pathing, with raid-specific enemy blocking. Solid placements preserve clone access to the return area, drill approach and wider land. Three return slots stay reserved. Recommended layout places gates before towers and walls.
- Infirmary and forge use 100 HP (unspecified in the plan). Footprints are anchored at their top-left cell. Refunds round down per resource; tower claims remain after demolition.
- Surface simulation pauses while away. An unattended active raid defers ordinary wipe/respawn handling so towers and raiders can finish. Pod loss removes `floor(30%)` of ore and crystal, destroys up to 1–2 seeded random buildings without refund, clears raiders and restores pod HP to 100.
- Persistence means retaining the surface object across trips; disk serialization was outside this plan.
