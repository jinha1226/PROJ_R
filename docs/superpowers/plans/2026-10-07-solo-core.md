# 1인 원정 핵심 (계획 C1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One clone goes down per run, a body can hold several souls (hybrid card offers, one player-aimed ultimate per soul), souls reach the base only by riding up (lift or return beacon), and death loses the body's souls and the unsent ones.

**Architecture:** A body's souls become `Unit.souls: BodySoul[]` (new `src/sim/party/body.ts`); class lines, memories, innates, weapon proficiency, duo cards and ultimates are all read from that list instead of a single class/soul/memory. The surface↔dungeon hand-off moves from "whole party" (`takeParty`/`placeParty`) to "one clone" (`takeClone`/`rejoin`), and a new `beacon.ts` opens a 5-turn portal that keeps the floor for re-entry. Promotions are removed first so later tasks do not have to carry them.

**Tech Stack:** TypeScript, Vite, Vitest, three.js view (unchanged here), Playwright smoke at plan end.

**Spec:** `docs/superpowers/specs/2026-10-07-solo-soul-design.md` (§1 원정 구조, §2.2, §5 영혼 여러 개, §8 첫 임무의 귀환 부분, §10). The beacon rules come from `docs/superpowers/specs/2026-10-07-rule-traits-design.md` §10.

**Later plans (not here):** C2 SF body (gun, suit, 8 empty-body cards, gravity grenade, workshop incl. soul-slot upgrade) · C3 class rework (6 classes × 8 cards, 강령술사, assassin rogue, new aimed ultimates incl. golem/shadow clone, 15 combo cards, summon AI, removal of the dormant advanced-class data) · C4 base life (working clones, first mission + soul tutorial, solo raids) · C5 presentation.

## Global Constraints

- All UI text is terse Korean; no explanatory AI-sounding copy (labels like `귀환 신호기`, `영혼 주입`).
- Every source file ≤ 500 lines (`node scripts/check-file-length.mjs`).
- Unit tests per task (`npx vitest run <file>`); e2e + CI only at plan end.
- `npm run typecheck` must pass at the end of every task (the removal tasks lean on the compiler to find callers).
- Base soul slots per body: **2** (`BASE_SOUL_SLOTS`); the upgrade that raises it is plan C2 — here only the field `RoamParty.soulSlots` exists.
- Beacon: **5 turns** to open (1 turn = 1 time unit), not usable in a fight, cancelled if a fight starts while opening (the use is not spent), **once per floor**, the floor is kept and `▼ 지하로` returns to the beacon spot.
- Death: the body and its souls are gone, unsent souls are gone, resources already counted (bio/ore/crystal/pack) are kept.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Rulings carried into this plan (decided while planning; the user sees them in the hand-off)

- A clone that rides up alive keeps its level, cards and souls, and may go down again; at the lab any living clone with a free slot can take another soul (not only empty bodies). — Cost if wrong: one guard in `implantCarried`.
- The empty body levels up too; until plan C2 adds its gun cards it is offered three common cards. — Cost if wrong: one line in `gainXp`.
- The first soul in a body sets its class, weapon and look; more souls add their card lines, innates, weapon proficiency, memory and ultimate. Body health uses the highest class health among its souls. — Cost if wrong: refitHp formula.
- Only the beacon keeps a floor; riding the lift at the floor start ends the floor as before. — Cost if wrong: Expedition keeps one more reference.
- Ultimates keep their current effects here; plan C3 replaces them with the aimed set. In this plan the aimed ones (화살비, 운석) take the chosen cell and the self-centred ones (함성, 결계, 그림자 난무) cast at once. — Cost if wrong: UI targeting branch.

## Review Focus

1. A run that returns with its time far ahead/behind the surface: every soul's `ultReady` must shift with the unit (otherwise a hybrid's second ultimate is locked for minutes). → test in Task 2.
2. Returning to a surface that still has other clones: none of them may be removed or moved (old `placeParty` wiped every hero). → test in Task 5.
3. The clone that went down was the surface's `'hero'` entity, and another clone is selected on return: ids and entities must not collide. → test in Task 5.
4. A fight starting while the beacon opens cancels it and the use remains; a fight already on refuses it. → test in Task 6.
5. Death after a beacon trip: the kept floor must be dropped so the next descent is a fresh floor 1 (no zombie floor with no clone). → test in Task 6.

```ts
import type { HeroSoulId } from '../delve/heroSouls';
import type { MemoryId } from './memories';
import type { BaseClass } from './partyDefs';
import type { Unit } from './partyCore';

/** A soul in a body: its class, the hero it was (if named), the memory it carried, when its ultimate is ready again. */
export interface BodySoul { cls: BaseClass; hero?: HeroSoulId; memory?: MemoryId; ultReady: number }
/** souls one body holds before the lab is upgraded */
export const BASE_SOUL_SLOTS = 2;

export const soulsOf = (u: Unit): BodySoul[] => u.souls ?? [];
/** the class lines the body's souls bring (the first is the body's own class) */
export const linesOf = (u: Unit): BaseClass[] => soulsOf(u).map((s) => s.cls);
export const memoriesOf = (u: Unit): MemoryId[] => soulsOf(u).flatMap((s) => (s.memory ? [s.memory] : []));
export const hasMemory = (u: Unit, id: MemoryId): boolean => soulsOf(u).some((s) => s.memory === id);
```

```ts
/** A soul goes into a body: the first sets its class, weapon and kit; any soul adds its line, memory and ultimate. Named heroes bring their level and cards. */
export function implant(p: RoamParty, u: Unit, soul: CarriedSoul, ev: GEvent[]): void {
  const s = typeof soul === 'string' ? { cls: soul } : soul;
  if (s.hero && p.combat) return;
  const cls = s.hero ? HERO_SOULS[s.hero].cls : s.cls, e = entOf(p, u.id)!, first = !soulsOf(u).length;
  u.souls = [...soulsOf(u), { cls, hero: s.hero, memory: s.memory, ultReady: p.time }];
  if (first) {
    u.cls = cls; u.weapon = CLASSES[cls].weapons[0]!; u.ready = [p.time, p.time]; u.queued = undefined;
    u.gear = starterGear(cls, () => nextItemId(p));
  }
  if (s.hero) {
    const h = HERO_SOULS[s.hero];
    if (levelOf(u) < h.level) { u.level = h.level; u.xp = LEVEL_XP[h.level - 1]!; }
    for (const [id, r] of Object.entries(h.traits)) u.traits = { ...u.traits, [id]: Math.max(rank(u, id), r ?? 0) };
    u.hero ??= s.hero; u.name ??= h.name;
    if (!p.foundHeroes.includes(s.hero)) p.foundHeroes.push(s.hero);
  }
  refitHp(p, u); e.hp = e.maxHp;
  ev.push({ t: p.time, type: 'buff', src: u.id, dst: u.id, text: 'soul' });
}

  p.carried.splice(at, 1);
  implant(p, u, soul, ev);
  return ev;
}
```

```ts
/** One clone leaves for the dungeon: it alone goes in the carry (souls stay stored at the base); it is taken off this map. */
export function takeClone(p: RoamParty, id: string): Carry {
  const all = takeParty(p), c = { ...all, clones: all.clones.filter((k) => k.unit.id === id), carried: [] };
  const e = entOf(p, id);
  if (e) { e.alive = false; e.pos = { x: -50, y: -50 }; }
  if (id !== 'hero') p.s.foes = p.s.foes.filter((f) => f.id !== id);
  p.units = p.units.filter((u) => u.id !== id);
  return c;
}

/**
 * The clones of a carry come back beside `at` and join the ones already here (nobody here moves). Their souls reach the base;
 * a run nobody came back from brings none (they were lost with it). The pack and resources are the carry's (this map waited).
 */
export function rejoin(p: RoamParty, c: Carry, at: Cell): void {
  const s = p.s, free = (x: Cell) => walkable(tileAt(s.map, x)) && !p.units.some((u) => alive(p, u) && same(entOf(p, u.id)!.pos, x));
  const spots: Cell[] = [];
  for (let r = 0; r < 4; r++) for (let dx = -r; dx <= r; dx++) for (let dy = -r; dy <= r; dy++) { const x = { x: at.x + dx, y: at.y + dy }; if (free(x) && !spots.some((o) => same(o, x))) spots.push(x); }
  c.clones.forEach((k, i) => {
    const pos = spots[i] ?? at, e = k.unit.id === 'hero' ? s.hero : spawnFoe(s, 'minion', pos, false);
    e.id = k.unit.id; e.pos = { ...pos }; e.hp = k.hp; e.maxHp = k.maxHp; e.alive = true; e.awake = false;
    const unit = structuredClone(k.unit);
    shiftUnitTimes(unit, p.time - c.time);
    p.units = [{ ...unit, shield: 0, order: null, queued: undefined } as Unit, ...p.units.filter((u) => u.id !== unit.id)];
  });
  p.pack = structuredClone(c.pack); p.nextItem = c.nextItem;
  p.ore = c.ore; p.crystal = c.crystal; p.bio = c.bio; p.nextClone = Math.max(p.nextClone, c.nextClone);
  p.foundHeroes = [...new Set([...p.foundHeroes, ...c.foundHeroes])];
  if (c.clones.length) p.carried = [...p.carried, ...structuredClone(c.carried)];
  p.combat = false; p.waiting = false; p.manual = undefined; p.over = false; p.rewakeAt = undefined;
```

```ts
// src/sim/delve/beacon.ts
import type { Cell, GEvent } from '../grid/types';
import { entOf } from '../party/partyCore';
import { living } from '../roam/roam';
import type { DelveParty } from './delveSim';

/** turns the portal takes to open */
export const BEACON_TURNS = 5;
export interface Beacon { at: Cell; openAt: number }

/** Out of a fight, once per floor, with a clone standing. */
export const canBeacon = (p: DelveParty): boolean => !p.combat && !p.beaconUsed && !p.beacon && living(p).length > 0;

/** The portal starts opening where the leading clone stands. */
export function startBeacon(p: DelveParty): GEvent[] {
  if (!canBeacon(p)) return [];
  const at = { ...entOf(p, p.leader ?? living(p)[0]!.id)!.pos };
  p.beacon = { at, openAt: p.time + BEACON_TURNS };
  return [{ t: p.time, type: 'buff', src: p.leader, text: 'beacon', to: at }];
}

/** A fight cuts the opening (the use stays); once open the floor is kept with its re-entry spot and the use is spent. */
export function beaconStep(p: DelveParty, ev: GEvent[]): void {
  if (!p.beacon) return;
  if (p.combat) { p.beacon = undefined; ev.push({ t: p.time, type: 'buff', text: 'beaconCut' }); return; }
  if (p.time < p.beacon.openAt) return;
  p.beaconAt = p.beacon.at; p.beacon = undefined; p.beaconUsed = true;
  ev.push({ t: p.time, type: 'buff', text: 'beaconOpen', to: p.beaconAt });
}
```
