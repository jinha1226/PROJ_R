# Smart Test Bot Implementation Plan

> **For agentic workers:** implement task by task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the naive policy in `tests/bot/runBot.ts` with a bot that plays like a competent player: it builds a coherent engraving build, fights with tactics (weapon stance, target priority, chokepoints, dodging telegraphs, resting), uses potions and scrolls at the right moments, and can play a whole campaign (many runs with the base meta carried between them).

**Architecture:** A `brain` folder under `tests/bot/` with one file per concern (view helpers, build scoring, items, tactics, policy, campaign). The bot only *reads* `GridState` and calls `GridSim.act()`. It never edits state (except the existing god mode HP refill). `runBot.ts` keeps the naive policy as `naive` for comparison.

**Tech Stack:** TypeScript, vitest. Run the bot with `npx vitest run -c tests/bot/vitest.bot.config.ts --silent=false`.

## Global Constraints

- **Do NOT modify anything under `src/`.** This is a measuring tool; balance is deliberately deferred. If you find a sim bug, describe it in your final output and do not fix it.
- Every file ≤ 300 lines (`npm run lint` enforces this, tests included).
- Deterministic: no `Math.random`, no `Date.now`. If you need randomness, derive it from the run seed.
- `npx tsc --noEmit`, `npm run lint` and `npm test` must pass.
- Do not commit or push.

## Game rules the bot must know (read from the code; summarised here)

- **Weapons:** `s.hero.gear.hands = [pistol, dagger('요원 칼')]` and `gear.active` is the index in hand. `{kind:'swap'}` toggles hands; it costs 0.5, or 0 with some engravings (`quickswap`). Moving into an adjacent foe is a melee attack **with the active weapon**. With the pistol in hand that is a weak bash (`HERO.bash` = 2–4). **The naive bot never swapped, which is why it died.** The dagger does real melee.
- **Charge:** shooting costs charge, `gunCost(s, weapon)` from `src/sim/grid/kataTargets.ts`; the start is 10 (`hero.charge` / `hero.maxCharge`). Charge refills on landed melee hits and melee kills (`src/sim/grid/suitCharge.ts`), plus some engravings and the `recharge` scroll. So the loop is: melee to fill, shoot to spend.
- **Shooting:** `{kind:'shoot', target}` needs the pistol active, `charge >= gunCost`, range and a clear line. `sim.autoTarget()` and `sim.shotChance(id)` help.
- **Corners:** no diagonal step or attack across a wall corner; use `canStep(s.map, from, dir)`. The same rule applies to foes.
- **Healing:**
  - Regen gives 1 HP per 6 turns while `canRegenerate(s)` (`src/sim/grid/regen.ts`): not burning or poisoned, and no awake visible foe within 8.
  - Belt healing potions: `gear.belt.potion` (start 2). `{kind:'use', item:'potion'}` heals `HERO.heal` = 25.
  - Engravings: `bloodlust`, `trance`, `poisonSiphon`.
- **Unidentified potions** `gear.potions[kind]` and **scrolls** `gear.scrolls[kind]`:
  - Names are hidden until known (`isKnown(s, potionKey(k))` in `src/sim/grid/lore.ts`). The bot may read the true kind from the state, but must **act as a fair player**: before a kind is known it may only drink, read or throw it to identify it.
  - Effects are in `src/sim/grid/consumables.ts`.
  - **Potions:**
    - strength: +str.
    - cure: clears statuses.
    - invis: 10 turns.
    - haste: 5 turns.
    - confuse: bad to drink, good to throw (radius 1).
    - fire, frost, poison: hurt you if drunk, good to throw at foes (radius 1).
  - **Scrolls:**
    - identify, map, teleport (escape).
    - fear: visible foes within 8 flee 5 turns.
    - lure: bad.
    - recharge: full charge.
    - engrave: an engraving offer.
- **Foes** (`FOES` in `src/sim/grid/types.ts`, AI in `ai.ts` and `boss.ts`):
  - minion: melee.
  - brute: melee, hits hard, slow (move 1.4).
  - ghoul: melee, fast (0.7).
  - archer: ranged 7, keeps 3–6 away, low HP.
  - mage: 4 HP. Marks a 3×3 area around the hero (`s.telegraphs`, entries with `cells`, `at`, `src`) that lands two mage turns later, so step out of it.
  - champion: on floors 5/10/15. Every 3rd turn it marks a whirl on the 8 cells around itself, landing next turn, so step out of ring 1. At half HP it summons 2 minions. Killing it opens the stairs (5, 10) or drops the core item on 15 (walk onto it to win).
  - Foes start asleep (`awake:false`).
  - Elites (`elite:true`) have 1.6× power. Elite and champion kills give an engraving offer from the foe's family (`FAMILY` in `absorb.ts`).
  - Wanderers arrive every 150 turns on a floor (`updateWanderers`), so do not rest forever.
- **Picks:**
  - `s.upgrades[0]` is a level-up offer of `UpgradeId`s: `{kind:'upgrade', i}`.
  - `s.offers[0]` is an engraving offer of `OfferCard`s: an `EngraveId` string, or `{kind:'round', element}` for an element round, max 2 rounds. Take it with `{kind:'choose', i, slot?}`.
  - The suit has `SUIT_SLOTS` = 6. When full, `slot` (the index to replace) is required, otherwise the pick is refused. `{kind:'choose', i:null}` passes.
- **Engravings:**
  - Catalogue: `ENGRAVES` in `src/sim/grid/engraveCore.ts` (family, tags, note), with triggers in `engraveDefs.ts` and `elementDefs.ts`.
  - Resonance: 3 of a family on the suit gives a family bonus (`resonance.ts`; ranged resonance lowers the pistol cost by 1, fusion lowers the chain threshold).
  - Element engravings only do anything if the hero has that element round (`hero.rounds`).
- **Meta:** `freshMeta()`, `settleRun(meta, s)`, `buy(meta, id)` with `SHOP` / `engraveShop(meta)`, `canRepair` / `repair(meta, id)`, `canCraft` / `craft` / `fit(meta, slot, id)` (mods), and `GridSim.createRun(seed, meta, {gun:'pistol', start:1, startSuit, round?})`. The start suit is limited to `meta.unlocked` and `meta.facilities.suitSlots`.

### Task 1: View helpers + policy skeleton + stance (swap and melee properly)

**Files:** `tests/bot/brain/view.ts`, `tests/bot/brain/policy.ts`, `tests/bot/runBot.ts`, `tests/unit/botBrain.test.ts`

**Produces (view.ts):**
- `adjacentFoes(s): Ent[]`: alive, Chebyshev distance 1, and `canStep` from the hero (corner rule).
- `awakeThreats(s): Ent[]`: alive, awake, and visible or within 8.
- `dangerCells(s): Set<number>`: map-index set of cells in telegraphs that land before or at the hero's next action plus one turn. Use `t.at <= s.hero.nextAt + 1.5` and include all pending telegraph cells, to be safe.
- `isChoke(s, c): boolean`: a walkable cell with ≤ 2 walkable orthogonal neighbours (a corridor or doorway).
- `gunReady(s): boolean`: `charge >= gunCost(s, pistol)`.
- `pistolIndex(s)`, `bladeIndex(s)`: indexes in `gear.hands` (by `WEAPONS[w.group].melee`).
- `stepToward(s, to): Cell | null`: the first step of `findPath` avoiding `walkBlocked`, falling back to a path that only avoids barrels (walking through found traps and bumping foes). This is the existing fallback, moved here.

**Behaviour (policy.ts):** `smartDecide(sim, mem: BotMemory): GAction`, where `BotMemory` is a mutable per-run object for counters and notes. For Task 1 it is: picks (always the first, as now), then the stance rules below, then the naive goals (core, stairs, explore, foes) via `stepToward`.

**Stance rules:**
- To melee an adjacent foe, the blade must be in hand. If the pistol is active, return `{kind:'swap'}` first.
- To shoot, the pistol must be in hand. If the blade is active, return `swap`.
- When `gunReady` and a shootable target exists and no foe is adjacent, shoot.
- When a foe is adjacent: melee it if not `gunReady`. If `gunReady`, compare the expected shot vs the blade (the simple rule is fine: shoot point-blank only if the build has `reverseCut` or `kite`, else melee).

**Tests (tests/unit/botBrain.test.ts):** build states with `GridSim.create(seed)` and edit them directly in the test (tests may edit state; the bot may not):
- An adjacent foe with the pistol active makes `smartDecide` return `{kind:'swap'}`. After the swap it returns a move into the foe.
- A telegraph covering the hero's cell puts the hero's index in `dangerCells`.
- `isChoke` is true for a corridor cell and false for a room centre (find them by scanning the map).

- [ ] Write the tests, see them fail, implement, see them pass. Run `npx vitest run tests/unit/botBrain.test.ts`.
- [ ] Wire `runBot(seed, {god, policy})` and keep the naive policy as is. Smart real mode must reach a higher average floor than naive over 10 seeds: print both.

### Task 2: Tactics

**Files:** `tests/bot/brain/tactics.ts`, `policy.ts`, tests.

**Produces:** `tactic(s, mem): GAction | null`, called by the policy after picks and emergencies.

**Behaviour, in priority order:**
1. **Dodge:** if the hero's cell is in `dangerCells`, step to an adjacent safe cell (not in danger, `canStep`, not occupied). Prefer cells with fewer adjacent foes, then cells that keep a target shootable.
2. **Target priority**, when shooting: mages and archers in range first; then a foe that dies to one shot (estimate with the weapon damage range and bonuses if easy, else lowest HP); then elites and champions (when the charge allows); then nearest. Use `sim.shotChance(id)` and skip shots under 35% unless nothing else is available.
3. **Melee target**, among adjacent foes: one that the blade can kill; then the lowest HP; prefer the one that is not a brute when choosing between equal options.
4. **Chokepoint:** if ≥ 2 awake melee foes (minion, brute, ghoul) are within 4 and the hero is not in a choke cell, and HP < 70% or ≥ 3 foes, move to the nearest choke cell within 4 steps that is not in danger. Skip this when the build wants to be surrounded (suit has `tempest` or `spinShot`) and HP ≥ 60%.
5. **Ranged foes out of reach:** if an archer or mage is visible but not shootable (no line, out of range, or no charge), close in along a path. Without charge, melee anything adjacent on the way.
6. **Charge loop:** with no charge and no adjacent foe, but an awake melee foe approaching, wait in place or in a choke (do not walk into several foes). With no charge and only ranged foes, close in.
7. **Sleeping foes:** do not wake a group needlessly. With the pistol ready and the build favouring openers (`headshot`, `sniper`, `steady`), shoot the sleeper from max range; `steady` wants a `wait` first. Otherwise approach and melee.
8. **Boss:**
   - The champion's whirl is covered by the dodge rule.
   - Before engaging a champion (first sighting), drink haste if known, and make sure HP ≥ 80% (rest first if no awake threats).
   - After the summon, kill the minions in a choke if HP < 50%.

**Rest** (in the policy, after tactics): if there are no awake threats and HP < 85%, and `canRegenerate(s)` is true, return `{kind:'wait'}`. Do this also before taking the stairs when HP < 85%. Stop resting if the floor time since `floorStart` is near the next wanderer wave and HP ≥ 60%.

**Tests:**
- A telegraph on the hero makes it step out to a non-danger cell.
- Two adjacent foes with the blade active, one at 1 HP: it attacks the 1 HP one.
- An archer and a minion both shootable, pistol ready: it shoots the archer.
- No threats, HP at 50%: it returns `wait`.

- [ ] TDD as above. Run the bot on 10 seeds and print smart vs naive real mode.

### Task 3: Items (potions, scrolls, belt) with fair identification

**Files:** `tests/bot/brain/items.ts`, `policy.ts`, tests.

**Produces:** `emergency(s, mem): GAction | null`, called right after picks, and `utility(s, mem): GAction | null`, called when no threats are awake.

**Fairness rule:** the bot may use a potion or scroll *by its effect* only if `isKnown`. Unknown items may only be used to identify them, under the conditions below.

**Emergency** (HP ≤ 35%, or HP ≤ 50% with ≥ 2 adjacent foes), in order:
1. The belt potion (`gear.belt.potion > 0`) if HP missing ≥ 15.
2. A known teleport scroll.
3. A known fear scroll if ≥ 2 foes are adjacent or near.
4. A known invis potion.
5. A known cure if burning or poisoned and HP ≤ 35%.
6. Otherwise retreat: step away to the cell that maximises the distance from awake melee foes, preferring choke cells.

**In-fight utility:**
- A known recharge scroll when charge < `gunCost` and ≥ 2 awake foes are visible.
- A known fire, frost, poison or confuse potion: throw it (`{kind:'throwPotion', p, at}`) at a cell where ≥ 2 foes are within radius 1, or at an elite or champion, never within distance 1 of the hero. Use `canThrow` from `src/sim/grid/explosives.ts` for validity.
- Known haste at a champion fight start, or with ≥ 3 awake foes.

**Safe-time utility** (no awake threats, HP ≥ 90%):
- Drink a known strength at once.
- Read a known engrave scroll at once. Read a known map scroll on arriving at a new floor.
- Identify: read an unknown scroll. Drink an unknown potion only at full HP with no foes awake within 12. Track what was learned (the sim's `isKnown` already does).
- Never read a known lure.

**Belt bombs and flasks:** if `gear.belt.bomb` or the flasks are > 0, throw them like harmful potions via `{kind:'use', item, at}`. Check `useThrown` in `src/sim/grid/explosives.ts` for the item names.

**Loot:** walk to visible floor items (potions, scrolls, materials, suits) and unopened chests within 12 steps when no threats are awake, before heading for the stairs.

**Tests:**
- HP 30% with a belt potion and a foe adjacent: `use potion`.
- An unknown potion while safe at full HP: it drinks it. An unknown potion with a foe awake: it does not.
- A known fire potion with two foes clustered at distance 3: it throws at their cell.

### Task 4: Build-aware picks

**Files:** `tests/bot/brain/build.ts`, `policy.ts`, tests.

**Produces:**
- `archetype(s): 'melee'|'ranged'|'fusion'|'element'`: the family with the highest weighted count on the suit. Ties go to fusion (the start suit is fusion: `gunRelay`, `spinShot`).
- `scoreCard(s, card): number` for an `OfferCard`.
- `scoreUpgrade(s, id): number`.
- `pickOffer(s): {kind:'choose', i:number|null, slot?:number}`: the best card. With a full suit, replace the lowest-scoring suit engraving if the new card is higher by > 1.5, else pass (`i:null`).
- `pickUpgrade(s): {kind:'upgrade', i}`.

**Card scoring** (keep the tables in `build.ts`; numbers are a starting point, tune if obviously bad):
- **Base tier** per engraving: strong core pieces 5 (`gunRelay`, `bladeRelay`, `momentum`, `flow`, `execute`, `cull`, `gale`, `tempest`, `spinShot`, `barrage`, `quickdraw`, `thrift`, `reclaim`, `bloodlust`, `trance`, `bayonet`); most others 3; weak or situational 2 (`kite`, `wallslam`, `rebound`, `muzzleShove`, `shoulder`, `laststand`).
- **Family synergy:** +2 if same family as the archetype; +3 more if this card makes the family count reach 3 (resonance).
- **Tag synergy:** +1 per shared tag with suit engravings. `처치` chains (kill-triggers) value `momentum`, `gale`, `flow`, `fury`. `기절` engravings value `execute` and `executionRush`. `회피` engravings value an evasion upgrade.
- **Charge economy:** if the suit has no charge sources (`reclaim`, `quickdraw`, `thrift`, `rebound`, `executionRush`, `fireEmber`, `shockCharge`) and the archetype is ranged or fusion, +2 for a charge source.
- **Element engravings:** worth 0 unless the hero has that element round (`hero.rounds`, element from the engraving's tags/id prefix fire/frost/shock/poison). Then base 3 + family synergy. `alternate` is valuable only with 2 rounds; `echo`/`chain` need ≥ 1 round.
- **Round cards:** the first round is 6. A second round is 4, +2 if the suit has `alternate`, and +1 per element engraving of that element.

**Upgrade scoring:**
- melee: `meleeDmg` 4, `killCharge` 3, `hp` 3.
- ranged: `gunDmg` 4, `charge` 3, `hp` 2.
- fusion: `killCharge` 4, `gunDmg` 3, `meleeDmg` 3.
- element: `gunDmg` 3, `charge` 3.
- `hp` +2 if maxHp < 60.
- `evasion` 4 if the suit has ≥ 2 `회피`-tagged engravings, else 1.

**Tests:**
- Fresh suit (`gunRelay`, `spinShot`) offered `[reclaim, kite, sniper]`: picks reclaim.
- Full 6-slot suit with a weak `kite` slot, offered `momentum`: replaces kite's slot.
- An element engraving without its round scores 0.

### Task 5: Campaign mode (meta carried between runs)

**Files:** `tests/bot/brain/campaign.ts`, `tests/bot/fullRun.bot.ts`, tests.

**Produces:** `runCampaign(seed, runs = 30): CampaignResult` with, per run: floor, outcome, killedBy, build, meta materials after, repairs and unlocked count. Also the index of the first win.

**Between runs:**
1. `meta = settleRun(meta, s)`.
2. Repairs in order `workbench`, `suitlab`, `nav`, `lifeSupport`, `pod` (never `core`; it ends the game) while `canRepair`.
3. Workbench: craft and fit mods that improve the archetype (gun mods for ranged and fusion, melee for melee; any `maxHp` or `shield` mod), while `canCraft`.
4. Shop (`buy`): element rounds (first fire, then shock), `suitSlots3`/`suitSlots4`, `chargePlus1`/`chargePlus2`, and engraving unlocks from `engraveShop` ranked by `scoreCard` against an empty suit plus archetype synergy. Spend energy greedily, highest value first.
5. Start suit: the best `meta.facilities.suitSlots` unlocked engravings by score. The start round is the first unlocked round, if any (`RunOptions.round`).
6. Always start at floor 1.

**Tests:** a 2-run campaign with fixed seeds is deterministic (same result twice), and run 2 starts with the meta settled from run 1 (energy or materials changed).
