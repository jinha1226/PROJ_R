# SF 빈 몸 (계획 C2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The empty body becomes a real SF class — pistol with a magazine, agent suit, eight condition cards, the gravity-grenade ultimate, a workshop at the base whose gun/suit modules bring it up to the fantasy classes, and the soul-slot upgrade. Two user requests ride along: a soul-stone tab and the beacon portal you must walk into.

**Architecture:** The empty body stays `cls: 'shell'` with no souls; its line is a new card pool `'shell'` and its kit gets proficiency `'gun'` and the ultimate `'gravity'`. Workshop state lives on the base (`RoamParty.sf`) and rides down in the `Carry`, so every shell body reads the same fitted modules (`sfStats`). The workshop screen is the gun-kata workbench restored from git (`a3824be^`) and re-pointed at the new model.

**Tech Stack:** TypeScript, Vite, Vitest, three.js (existing `Gun_Pistol` model in `weaponKit`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-solo-soul-design.md` §2.1, §4.7, §6 (작업장), §5 (영혼 칸 확장). Beacon: `2026-10-07-rule-traits-design.md` §10 as amended by the user on 2026-10-07 (below).

## Global Constraints

- Terse Korean UI; no explanatory AI-sounding copy.
- Every source file ≤ 500 lines; `npm run typecheck`, `npm run lint` pass after every task.
- Unit tests per task; e2e + CI at plan end. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Materials are the game's current ones: 광석 `ore`, 마정석 `crystal`, 생체 `bio`.
- **Beacon (user, 2026-10-07):** the portal opens at the spot the beacon was used, **5 turns** after use; once open it stays **5 turns** and the clone must **walk onto it** to ride up. A fight while it is still opening cancels it (use kept); once open it stays open fight or not. Not entered in time → it closes and the floor's use is spent.
- **Souls:** stones keep being picked up below (they wait unsent until the clone rides up). **A stone picked up below is unidentified (미감정)** (user, 2026-10-07): its class shows (stone colour), its memory shows `???`, a hero stone shows only `미감정 영웅 영혼석`; it is identified when it reaches the base (lift or beacon). The new `영혼석` tab lists every stored/unsent stone: class, memory (the soul's base trait) and, for a named hero, name, level and cards — or the unidentified form.
- Magazine: **6** shots; at 0 the clone's next attack is a reload (one attack's time × reload factor).
- Soul-slot upgrade: unlimited, cost in crystal `10 × 2^(bought)`.

## Rulings carried into this plan

- Empty-body health becomes **40** (the agent suit) instead of 30. — cost if wrong: one number.
- Workshop (user, 2026-10-07, option A): no stat modules; dismantling fantasy weapons/armour opens effect blueprints and powers the gun/suit like sacrifice; the magazine is fixed at 6.
- The workshop applies only to empty bodies (soul-infused bodies are fully fantasy, spec §2.2).
- The workshop opens from a `⚒ 작업장` prompt at the lab (next to `클론 생성`); the soul-slot upgrade sits in the workshop footer.
