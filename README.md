# PROJ_R

이름 없는 초보 모험가 한 명으로 시작해 동료를 영입하고, 최고의 용병단으로 성장하는
로그라이크 오토배틀 RPG입니다. (개발 중 — 1차 마일스톤: 수직 슬라이스)

- 플레이: https://jinha1226.github.io/PROJ_R/
- 설계서: [docs/superpowers/specs](docs/superpowers/specs/2026-10-01-mercenary-roguelike-design.md)
- 구현 계획: [docs/superpowers/plans](docs/superpowers/plans/)

## 여정 (본 게임)

첫 화면에서 `새 여정`을 누르면 이름 없는 모험가 혼자 잿빛 변경 지도(12단계 × 3갈래)를 나아갑니다.

- 노드: 전투 · 정예 · 만남(영입) · 사건 · 휴식 · 상점 · 12단계 보스 "잿빛 기사"
- 전투 전 3×4 칸에 진형을 짜면 인접한 관계 효과(친구 방어↑, 라이벌 공속·치명↑, 반목 공격↓, 전우 연계기)를 미리 볼 수 있습니다.
- 첫 동료를 영입하면 주인공의 이름을 정합니다. 용병단은 최대 8명, 출전은 5명.
- 패배하면 후퇴(전원 부상, 골드 30% 손실). 주인공이 죽거나 전원이 쓰러지거나 보스에게 지면 여정이 끝납니다.
- 보스를 쓰러뜨리면 용병단 이름을 짓고 명예의 전당에 기록됩니다. 진행은 자동 저장되며 `이어하기`로 계속합니다.

## 전투 샌드박스

아군 프리셋(혼자인 견습 / 기본 5인 / 원소 연계)과 적 프리셋(해골 졸개 / 산적단 / 해골 부대 / 보스)을 고르고
시드를 정해 자동 전투를 관전합니다. 같은 시드는 항상 같은 전투를 재현합니다.

- `Space` 일시정지 · `1` `2` `3` 속도 1x/2x/4x · `후퇴` 버튼
- 상단 이름표나 캐릭터를 클릭하면 현재 의도와 그 이유(전술·상황)를 보여줍니다.
- 전투 기록의 `연계·구출만`으로 중요한 순간만 볼 수 있습니다.
- 카메라: 휠 확대/축소, 드래그 이동, `WASD`/방향키 이동, `Q` `E` 줌, `C` 또는 `자동 카메라`로 자동 추적 복귀
- `H` 또는 `행동 표시`로 머리 위 현재 행동 표시를 켜고 끕니다.
- 아군 `관계 시연 파티` + 적 `산적 매복`을 고르면 성격·관계 행동(엄호, 라이벌 경쟁, 복수, 용기, 반목, 전우 연계기)을 볼 수 있습니다.

## 용병단 모드 (성장 체험)

샌드박스 화면의 `용병단 모드`를 누르면 이름 없는 모험가와 신입 4명으로 용병단을 꾸려 연속으로 전투합니다.

- 전투가 끝나면 경험치·레벨업·부상·흉터·사망·별명·숨은 성격·전리품·"이번 전투의 순간들"이 정리됩니다.
- 레벨업마다 새 기술 / 기술 강화 / 패시브 / 전술 중 3택 1. 견습 모험가는 레벨 3에 직업을 고릅니다.
- 카드를 누르면 캐릭터 시트(능력치·스킬·장비·관계·연대기). 장비는 보관함에서 장착하며, 등급이 오를수록 외형 색이 바뀝니다.
- 베테랑(Lv7)은 망토, 영웅(Lv10)은 금빛 오라가 생깁니다. 아직 저장 기능은 없습니다(새로고침 시 초기화).

## 개발

Node.js 22 이상.

```sh
npm ci
npm run dev        # 개발 서버
npm test           # 단위·시뮬레이션 테스트 (Vitest)
npm run lint       # ESLint + 파일 길이(300줄) 검사
npm run typecheck  # TypeScript 검사
npm run build      # dist/ 정적 빌드
npm run e2e        # Playwright 브라우저 테스트 (빌드 후)
npm run assets     # KayKit 원본에서 public/assets 재생성
```

`main`에 푸시하면 GitHub Actions가 검사를 모두 통과한 빌드를 GitHub Pages에 배포합니다.
