# PROJ_R

이름 없는 초보 모험가 한 명으로 시작해 동료를 영입하고, 최고의 용병단으로 성장하는
로그라이크 오토배틀 RPG입니다. (개발 중 — 1차 마일스톤: 수직 슬라이스)

- 플레이: https://jinha1226.github.io/PROJ_R/
- 설계서: [docs/superpowers/specs](docs/superpowers/specs/2026-10-01-mercenary-roguelike-design.md)
- 구현 계획: [docs/superpowers/plans](docs/superpowers/plans/)

## 여정 (본 게임)

첫 화면에서 `새 여정`을 누르면 이름 없는 모험가 혼자 잿빛 변경에서 **12주**를 보냅니다. 12주차에 잿빛 기사가 습격해 옵니다.

- **주 시작**: 일거리를 찾는 방문자(2주차부터, 2주차는 확정)를 영입하거나 돌려보내고, 가끔 주 시작 사건이 벌어집니다.
  첫 동료를 영입하면 주인공의 이름을 정합니다. 용병단은 최대 8명.
- **이번 주에 할 일** (하나만):
  - **탐험**: 지역 카드 3장(숲 · 던전 · 묘지, ★1~3, 보상 경향) 중 하나를 골라 최대 5명으로 출정합니다.
  - **훈련**: 고른 동료가 위험 없이 경험치를 얻습니다(가끔 대련 → 라이벌).
  - **휴식**: 전원 부상 회복 + 두 사람의 대화(친밀도 상승).
  - 상점은 주 1회 재고가 바뀌며 언제든 들를 수 있습니다.
- **탐험 맵**: 방이 통로로 이어진 구역을 주인공을 직접 움직여 돌아다닙니다(동료는 줄지어 따라옴, 안 가 본 방은 안개).
  - 키보드 `WASD`/방향키 이동 · `E` 상호작용 · `Esc` 귀환 확인 · `Z` `X` 카메라 90° 회전
  - 조이패드 왼쪽 스틱 이동 · Ⓐ 상호작용 · Ⓑ 취소 · LB/RB 카메라 회전
  - 적이 서 있는 방에 들어서면 **그 방이 전장**입니다. 들어온 문 쪽에서 진형대로 시작하고, 방의 상자·기둥·나무가 엄폐물이 됩니다.
  - 보물상자 · 사건 · 모닥불(부상 회복) · 출구. 출구나 `귀환`으로 얻은 것을 갖고 돌아옵니다.
  - 전투에서 지면 후퇴(참전자 부상, 골드 30% 손실)하고 탐험이 끝납니다.
- **주 마감 보고** 후 레벨업을 고르고 다음 주로 넘어갑니다.
- 주인공이 죽거나 전원이 쓰러지거나 보스에게 지면 여정이 끝납니다. 보스를 쓰러뜨리면 용병단 이름을 짓고 명예의 전당에 오릅니다.
- 진행은 행동마다 자동 저장되며 `이어하기`로 계속합니다. 전투 도중 새로고침하면 후퇴로 처리됩니다.

전투는 아이소메트릭 시점(`Z` `X` 회전, 휠 줌, 드래그 이동)으로 자동 진행됩니다.

## 출격 — 파티 익스트랙션

타이틀의 `출격 (시험)`으로 들어가는 모드입니다(주간 게임과 저장 분리). 용병 최대 5명을 이끌고 위험 지역에 들어가 **전리품과 동료를 살려서 데려오는 것**이 목표입니다. 공격 버튼은 없습니다. 어디로 갈지, 무엇을 조사할지, 언제 싸움을 끊을지, 언제 나갈지를 정합니다.

- **용병단 거점**: 용병 3명(특별한 주인공 없음)으로 시작, 최대 8명. 선술집에서 영입, 파티 편성(맨 앞 = 리더), 용병별 장비 8부위, 창고·상인, 출격 짐(공용), 안전 주머니(전멸해도 남음).
- **이동**: 리더만 움직이면 파티가 진형을 짜서 따라옵니다(좁은 길에서는 줄을 섭니다).
- **전투는 자동**: 직업·성격·관계대로 싸웁니다. 명령은 세 가지 — `F` 집중 공격(정면의 적, 눈치채지 못한 적이면 기습) · `R` 후퇴 · `G` 재집결. 리더를 움직이면 리더만 직접 움직입니다.
- **손실**: 쓰러진 동료는 다른 동료가 일으켜 세울 수 있지만, 생명줄이 다하면 영구히 죽습니다. 시체에서 장비를 되찾을 수 있고, 그만큼 짐 칸이 줄어듭니다. 용병단에 아무도 남지 않으면 게임 오버.
- **탈출**: 서 있는 파티원 모두가 탈출 지점 안에서 8초 버티면 성공. 맞으면 2초씩 밀리고, 쓰러진 동료가 있으면 느려집니다. 지점 밖에 남은 동료는 돌아오지 못합니다.
- **위험 시계**: 4분 해질녘(순찰 증가) → 6분 30초 경고 → 8분 밤(탈출 지점 하나 닫힘) → 10분 마력 폭풍(사냥꾼).
- **루팅**: 동전·잡동사니·흔한 재료·물약은 지나가기만 해도 줍습니다(1.5m). 상자는 조사(일반 1초 · 보급 1.5초 · 유물/보물방 2초)가 끝나면 좋은 것부터 짐에 자동으로 들어갑니다. 귀한 물건(3등급 이상·유물)을 찾았거나 칸·무게가 모자랄 때만 선택 창이 뜹니다. 손으로 내려놓은 물건은 다시 줍지 않습니다. 조사 중 적이 다가오면 끊기고, 동료들은 바깥을 보고 경계합니다.
- **속도감**: 출격에서는 이동이 1.3배, 공격·스킬 동작과 재사용 대기가 1.33배 빠릅니다(아레나·용병단 모드는 그대로).
- **모바일**: 세로로 들면 세로 전용 화면(상단 정보 띠, 파티 칩, 아래쪽 엄지 영역에 스틱·명령 버튼, 아래에서 올라오는 짐 창), 가로로 돌리면 가로 화면 — 출격 중에 돌려도 그대로 이어집니다.
- **줌**: `＋` `−` 버튼, 마우스 휠, 빈 땅에서 두 손가락 핀치. 세로·가로 각각 기억합니다(기본 세로 15m · 가로 11m).
- 조작: 키보드 `WASD` 리더 이동 · `F` `R` `G` 명령 · `E` 조사/줍기 · `Esc` 짐·일시정지 · `Z` `X` 카메라 · 휠 줌 / 패드 스틱 · Ⓧ 집중 · Ⓨ 후퇴 · RB 재집결 · Ⓑ 조사 · Start / 터치 왼쪽 스틱 + 오른쪽 명령 버튼 · 핀치 줌.

## 전투 샌드박스

아군 프리셋(혼자인 견습 / 기본 5인 / 원소 연계)과 적 프리셋(해골 졸개 / 산적단 / 해골 부대 / 보스)을 고르고
시드를 정해 자동 전투를 관전합니다. 같은 시드는 항상 같은 전투를 재현합니다.

- `Space` 일시정지 · `1` `2` `3` 속도 1x/2x/4x · `후퇴` 버튼
- 상단 이름표나 캐릭터를 클릭하면 현재 의도와 그 이유(전술·상황)를 보여줍니다.
- 전투 기록의 `연계·구출만`으로 중요한 순간만 볼 수 있습니다.
- 카메라: 휠 확대/축소, 드래그 이동, `WASD`/방향키 이동, `Q` `E` 줌, `C` 또는 `자동 카메라`로 자동 추적 복귀
- `H` 또는 `행동 표시`로 머리 위 현재 행동 표시를 켜고 끕니다.
- 아군 `관계 시연 파티` + 적 `산적 매복`을 고르면 성격·관계 행동(엄호, 라이벌 경쟁, 복수, 용기, 반목, 전우 연계기)을 볼 수 있습니다.

## 용병단 모드 (성장 체험)

샌드박스 화면의 `용병단 모드`를 누르면 이름 없는 모험가와 신입 4명으로 용병단을 꾸려 연속으로 전투합니다.

- 전투가 끝나면 경험치·레벨업·부상·흉터·사망·별명·숨은 성격·전리품·"이번 전투의 순간들"이 정리됩니다.
- 레벨업마다 새 기술 / 기술 강화 / 패시브 / 전술 중 3택 1. 견습 모험가는 레벨 3에 직업을 고릅니다.
- 카드를 누르면 캐릭터 시트(능력치·스킬·장비·관계·연대기). 장비는 보관함에서 장착하며, 등급이 오를수록 외형 색이 바뀝니다.
- 베테랑(Lv7)은 망토, 영웅(Lv10)은 금빛 오라가 생깁니다. 아직 저장 기능은 없습니다(새로고침 시 초기화).

## 개발

Node.js 22 이상.

```sh
npm ci
npm run dev        # 개발 서버
npm test           # 단위·시뮬레이션 테스트 (Vitest)
npm run lint       # ESLint + 파일 길이(300줄) 검사
npm run typecheck  # TypeScript 검사
npm run build      # dist/ 정적 빌드
npm run e2e        # Playwright 브라우저 테스트 (빌드 후)
npm run assets     # KayKit 원본에서 public/assets 재생성
```

`main`에 푸시하면 GitHub Actions가 검사를 모두 통과한 빌드를 GitHub Pages에 배포합니다.
